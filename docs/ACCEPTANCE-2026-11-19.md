## 验证方法

- 主机执行现有测试命令矩阵、额外的草稿／压缩／退出检查，以及最终失败项复验。
  原生 CTest、扫描器测试和 package 检查分别记录，不将主机硬件跳过项算作通过。
- 实机按作用域隔离完整应用私有目录和公共传输目录；结束时核对恢复哈希、宿主 PID、
  boot ID 和安装原生 ELF。只停止／启动 PenChat，不重启系统 MiniApp 宿主。
- 普通界面、官方输入、扫描采集、原图、设置、缩放／字体、30/60Hz、菜单、会话、
  重试／分支、导入导出及辅助任务使用真实触控和本地假服务。
- 真实后台探针由当前开发包配对生成，只改变一次性自身后台定时器及测试标记；
  每个 assets/libs 字节与普通包一致。退出测试后重新安装普通包并核对标记已清除，
  再恢复原用户数据。旧版本硬编码哈希的探针拒绝执行不算当前设备功能失败或通过。
- DeepSeek 压缩检查完整归档、摘要持久化、重启恢复、未发送草稿保留和未额外发送聊天；
  Y02 仅运行假服务。临时凭据使用受限权限，验收后删除。
- 设备持续操作观察使用长草稿、键盘输入／关闭和同一模型身份核对；不把
  `--cycles 0` 或注入电源键算作真实物理熄屏验收。
