# PenChat 0.2.21

- 新增在线更新：启动时检查一次，也可在设置中手动检查。
- 可选择稍后更新；下载可取消，校验成功后自动安装并恢复聊天、草稿和待发送图片。
- 更新说明按版本累积展示，支持长说明分页。
- 自动选择低延迟节点，1至8路分段下载；主节点较慢且另一节点确认提供相同文件时启用双节点合流。
- 校验安装包哈希、ZIP完整性、AppID及版本，异常发布不会覆盖现有应用；支持失败后手动重试。
- 适配ORANGE及Y02/113的原生安装接口，全程不执行shell、不重启系统MiniApp宿主。

0.2.20及更早版本需要先手动安装本版本，之后才能使用内置更新。没有SHA-256文件的版本会明确提醒；格式错误或校验不一致不可绕过。
