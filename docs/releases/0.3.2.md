# PenChat 0.3.2

## 界面与阅读

- 新增深色／浅色主题、75%–150% 界面缩放和全局文字大小设置，设置保存后立即生效。
- 提供 30／60 Hz 刷新目标，横屏默认 30，竖屏默认 60；改善滚动、输入框收起和回到底部按钮的稳定性。
- 优化 Markdown 字重、行距、段落、标题与列表排版，改善窄屏阅读和输入框遮挡。
- 改善历史抽屉、键盘与菜单过渡，完善空状态指引和较大字号下的控件布局。

## 输入与聊天

- 完善 Y07 官方键盘的保留页面、光标拖动、选区、复制剪切粘贴和发送；直接收起保留已输入内容，点加号不结束编辑。
- 所有原生键盘布局支持单击当前光标唤出编辑菜单，空输入框也能唤出粘贴。
- 改善拼音候选与预编辑位置、浅色键帽及输入框与官方键盘之间的主题衔接。
- 思考期间的联网搜索状态保留在思考过程中，推理强度仪表随当前档位更新。
- 统一 Provider 表单保存入口，保留已有配置、模型与历史关联。
- 默认提示 AI 避免输出暂不支持显示的表情包；用户明确要求时仍可输出。

## 稳定性

- 完善菜单滚动、边缘返回、生命周期与过期输入回调的隔离，避免误关闭、重复操作及遗留控件引用。
- 保留会话、草稿、附件和现有设置；各硬件架构使用独立的完整安装包。

设备与验收范围以本版本正式发布附件和验收记录为准。
