# Markdown 表格边界兼容

加粗小标题或普通段落后紧接表格、未留空行时，当前 MD4C 会将其视为
同一段落。原生渲染器现在只在可确认的表格前补显示用的段落边界，聊天
原文、复制全文、数据库和导出文件不变。

兼容条件：至少两列；分隔行每列至少三个短横线，可带对齐冒号；表头、
分隔行和至少一行非空数据列数相同。支持可选外侧竖线及转义竖线。
单列表格、缺少数据行和不确定的写法不额外修复，原有标准解析继续处理。

先寻找有界候选，只有发现候选才用现有 MD4C 检查它是否位于顶层普通
段落。围栏代码、缩进代码、跨行行内代码／数学内容不插入边界；列表、
引用容器保持原有解析。不把普通带竖线的文字猜成表格。

相关检查：`penchat-markdown-tables`、`penchat-markdown-wrap`、
`penchat-text-selection`、`tests/test_markdown_tables_ui.py`。新用例使用
虚构文本，用户故障原文与设备截图仅保存在忽略的私有工作目录。

本轮定向结果：故障原文从零张恢复为两张表格；边界与代码保护、标点
换行、文本选择用例通过。三类布局的100%／150%字号均确认只有正文
表格进入表格布局，代码块和普通竖线保留原样。两架构编译与开发包
身份、资源、架构检查通过；未执行全套发布测试。
