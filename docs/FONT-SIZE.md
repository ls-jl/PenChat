# 全应用字体大小

设置 → 应用 → 字体大小：75%～150%，以各文字角色原有字号为100%，每档5%。
调节页只改变局部文字示例；“保存”经数据库后台任务确认成功后应用，
“恢复默认”只把预览复位至100%，返回会放弃未保存调整。保存失败保留原倍率和
预览值，可直接重试。后台或系统面板打开期间等待前台输入许可恢复后再重建界面。

字号偏好覆盖菜单、按钮、页面标题、表单、输入框、键盘与候选、剪贴板、
普通及归档聊天的用户正文、AI Markdown、公开思考、代码、表格与数学公式。
标题、说明和正文保留各自层级；公式保留相对正文的原有系数。
放大文字后按实际字体行框测量表单、设置行、页头与必要的按钮高度，
长的固定行标题仍用单行省略，列表和页面内容可以滚动。

“界面缩放”继续独立控制控件、间距和图标。字体最终像素为设计字号乘以
设备density、界面倍率和字体倍率，所有因子组合后只取整一次；已经解析的像素
不会再次缩放。文字变化会重新测量气泡、换行、表格和链接命中范围，
流式排版与离屏分块绘制使用同一字号，不改变原始Markdown、图片或传感器像素。

键盘保留完整键序和触摸网格，几何通过独立界面倍率适配。候选、拼音、菜单
使用所选最终字号；某种布局的按键文字实际放不进键帽时，只把该布局的字母与
按键功能文字逐像素收小到可容纳，不裁掉按键或扩大重叠命中区。
几何仍无法容纳时继续使用界面倍率的既有向下适配策略。

为兼容已有安装，字体设置继续使用`app_settings.reading_font_percent`整数键，
没有新增同义设置或数据库结构。缺省或类型损坏用100%，整数超界限制至75～150，
包括旧版保存的200%。原值现在作用于全应用文字；`ui_scale_percent`保持独立。
主机命令行的界面缩放覆盖不会改写任何已保存字号。原桥接appearance包继续传递
已经组合完成的标题、正文和说明像素，Falcon输入矩形仍使用原逻辑坐标。

## 当前定向验证

- `penchat-ui-metrics-tests`覆盖独立几何、所有语义字体角色、三因子一次取整及旧键校验。
- `tests/test_global_font_size.py`覆盖宽横屏、紧凑横屏和竖屏；验证75/100/150%、
  局部预览、返回取消、设置行实际范围、保存失败/重试、重启、appearance字体和独立界面缩放。
- `tests/test_font_size.py`保留普通与归档聊天的75/100/125/150%、气泡与富文本重排、
  草稿、滑条、恢复默认、旧超界配置及Responses/Chat Completions流式内容完整性。
- `tests/test_keyboard_text_size.py`检查各键盘布局的字体角色、完整键帽/命中范围和实际文字容纳。

以上是主机定向检查范围，设备触摸与视觉验收、完整发布回归记录另列，不将历史
0.1.57/0.1.58的阅读字号验收视为本次全应用字体变更已完成设备验收。
