# 阅读字号（0.1.57）

设置 → 阅读与显示 → 字体大小：75%～200%，以原有字号为 100%，每档 5%。
调节页实时预览；“保存”应用并写入应用设置，“恢复默认”将预览复位至 100%，
返回则放弃未保存的调整。返回设置后恢复原列表位置。

作用于普通及归档聊天的用户正文、AI Markdown、公开思考、代码、表格与数学公式。
菜单、按钮和键盘保持原尺寸。字号变化重新测量气泡、换行、表格和链接点击范围；
公式继续保留原有相对正文的 1.5 倍系数，不改变原始 Markdown 或图片尺寸。
流式排版和离屏分块绘制共用同一字号。标题保留相对正文的层级比例。

使用独立应用设置 `reading_font_percent`，缺省 100；损坏或类型错误恢复默认，
整数超界限制到 75～200。不修改数据库结构、会话配置或桥接协议。
