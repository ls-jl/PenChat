# 0.2.31：扫描尾部几何保护

## 观察及处理范围

Y02真实结果的前半段文字连续，尾端出现明显斜转、叠片。该笔接收342帧，选中298帧、13批，
累计缺7帧、5次断档均已按既有策略续扫；未定位和内存判停为0。用户确认收笔时有抬起或转动。
截图与1024像素共享预览仅留在忽略目录，没有使用或发送此图。

代码检查发现：模型输出经过DFL解码后，有限但严重失真的透视矩阵仍可能通过原有奇异/越界检查，
直接覆盖已拼接内容；原流程没有将预测变换与相邻实际图像核对。此次尚无该笔逐帧输入与模型输出，
因此不能据预览断言每一处形变来自哪一路输出，也不把累计缺帧等同于尾部形变的充分解释。

本次修复在绘制前拒绝不可信几何，保留此前画布并返回明确部分结果；**不声称已恢复离纸失焦后
不存在的图像细节，也不声称已经把所有错误尾帧重新对齐**。不改变模型、输入填充、32/24/8窗口、
解码累积、筛选、光照、原始分辨率、驱动同步及各机型丢帧策略。

## 绘制前检查

- 在160×288模型工作坐标检查3×3采样点的投影分母与局部Jacobian；拒绝翻折、投影地平线及严重拉伸。
  广义安全范围为局部伸缩1/8～8、各向异性不超过12、分母最大/最小绝对值比不超过8。
  这些是本地安全界限，不冒充模型训练范围或厂商置信度。
- 保留最近8张80×144模型小图及其位姿，按动态内存预算申请94,208字节页内存。
  不再持有完整原帧，不增加整图副本或模型设备缓冲；收尾、取消和销毁释放。
- 相对参考发生8度以上转动或明显伸缩变化时，验证变换下的归一化相关性。
  从较早参考开始，避免连续小幅错误转动绕过相邻帧检查；有图像依据的大角度旋转正常保留，
  没有绝对角度禁区。
- 最多8个参考；每次相关性固定采样，要求至少160个有效点、双方方差均不少于50。
  仅搜索模型小图上±2像素的9个平移位置；有可接受匹配立即结束。最佳相关性低于0.2才判为明确不匹配。
  重叠不足或低纹理属于未知，不单凭它宣称匹配失败；因此保护不是所有困难画面的质量保证。
- 新帧未通过时尚未修改画布。停止接收新帧，排空已接收工作并将未入画原帧记为未定位，
  不静默丢帧、不补造像素、不偷偷降低分辨率。界面显示“角度或对齐异常”，按钮为“使用部分图像”。
  只有用户确认才写入待发送区。下一笔有全新的几何检查状态，健康模型继续常驻。
- 几何停止原因也在采集入口的互斥状态中保存；采集回调先于停止事件到达时，返回相同原因，
  不把正常的主动停扫误标为内存申请失败。几何停止保持部分定位状态，不冒充容量停止。
