# 系统控制中心与原生页面交接

PenChat 使用独立 DRM 图层。Y07 的系统控制中心可以在未触发页面 `onHide` 的情况下覆盖
MiniApp，并且 `$am.hasWindowFocus()` 仍然返回有焦点。只启用 `setSupportTopPanel(true)`
会让系统面板在底层打开，原生页面仍挡住显示并继续读取触摸。

## 交接方式

- 启动器复用现有轮询，每100ms最多查询一次窗口焦点和系统面板可见状态，仅在状态变化时发送
  `window.focus`；发送失败保留待交接状态。页面后台后停止轮询，恢复时立即核对。
- 焦点使用系统 `$am` 模块。控制中心可见状态由桥接读取已加载 Falcon 的具名导出
  `_setting_panel` 与 `NWindow::isShowing()`；系统自身 `SettingPanel::bringToFront()`
  使用相同的窗口方法。只读查询，没有对象偏移、固定地址、函数补丁、额外框架实例或系统配置修改。
  符号、对象未就绪时不调用；不使用会逐次输出日志的手势辅助函数。
- 临时覆盖与真实页面后台分开处理。面板出现时禁用原生图层、关闭原生触摸fd并结束当前触摸，
  停止相机/OCR；保留页面、抽屉、草稿、组合拼音、阅读位置及已持有的扫描结果。
  已存在的扫描处理/原图读取继续持有结果，不通过普通注销路径提前销毁。
- 系统面板关闭后恢复原图层和当前页面，重新同步硬件资格。网络接收和数据库保存不会因面板打开而重发。
- 竖屏顶部圆角安全区中的新触摸交给系统手势，不滚动下方聊天。该保护仅处理触摸消息，
  不得拦截滑动尚未松手时到达的面板状态、生命周期或退出消息。
- 真实 Home/后台/退出继续走原有清理路径。内置键盘、裁剪和图片浏览仍保留此前的下拉屏蔽策略。

`system_overlay` 诊断仅记录接口可用性及可见/焦点布尔值，不记录用户内容、窗口截图或凭据。
桥接版本和数据库结构不变。

## 0.3.1 接触取消与弹层退场

弹层退场期间开始的接触由 popup 输入吸收，直到同一接触释放。失焦或输入租约过期时，

此时旧释放帧可能被焦点规则拒收，不能让旧的释放吸收状态吞掉恢复后的首个独立点击。
抽屉、草稿和阅读位置继续保留；输入300ms、媒体1500ms租约与触摸设备所有权不变。
`test_input_focus.py` 使用真实退场接触、失焦、拒收旧释放和恢复后一次点击覆盖该路径，
并保留原有过期序号、卡住心跳、取消点击及滚动位置断言。

### 官方输入时的聊天操作

官方键盘保留系统按键与选词；光标和选区由原生编辑器处理。有效的前台竖屏租约允许读取原生触摸，
分别处理阅读滚动与实际可见控件的单指点击；移动超过 12dp、多指和取消均不激活动作。
加号直接打开键盘上方的局部滚动菜单，不确认或关闭官方编辑；菜单关闭也保留键盘。
只有始于原生可见区域的菜单触摸进入 LVGL，系统键盘触摸不能关闭或激活菜单。
发送、推理强度及菜单选项切换到其他功能前请求代理输入框确认，通过 requestId、actionId
和会话身份匹配，关闭编辑后在 UI 队列执行。停止生成及回到底部直接执行并保留编辑。
竖屏官方编辑实时生效：直接收起保留最新代理文本，故障回退也保留文本；不恢复打开前
的快照。横屏全屏官方编辑仍使用原来的显式确认／取消。

Y07 的 `commitComplete()` 只确认已经上屏的代理文本，不能保证提交仍在官方候选区的拼音。
因此记录系统键盘新触点时间，并仅由真实文本输入事件确认；光标轮询不算确认。
未确认时保留键盘与输入，提示先完成选词或官方确认后再点击。非文本键也可能触发这项
保守保护；不读取系统拼音解码器。内核时间戳只用于跨进程事件排序，不改变触摸映射。
超时、后台、系统面板、请求替换及重复确认均不能触发发送。

### 官方键盘中的原生文本操作

竖屏官方输入连接保留在屏幕边缘的 1×1 逻辑像素位置，用于接收系统按键与候选词。
这只是不可交互连接的边界，不是 UI 设计尺寸。实际输入框只由原生触摸驱动，复用现有
光标、长按拖动、选区手柄、放大镜与全选／复制／粘贴／剪切／撤销菜单，不再让两套
不同排版同时决定光标位置。

`keyboard.edit` 带当前请求、递增序号和基准文本；代理拒绝过期身份及不同基准，返回
`keyboard.edit.result`，不会覆盖更晚的系统输入。只有显式文本编辑才调用 `commitText`，
光标／选区移动仅设置光标，普通逐字输入不反复重写整个文本。异步光标轮询丢弃编辑前
的旧结果。官方 API 没有选区接口，原生选区在真实提交输入后替换，保留选区两侧文本；
未确认拼音不参与替换。桥接偏移为 UTF-16，原生保持既有字素边界。

定向测试 `tests/test_official_text_edit.py` 覆盖光标、长按拖动、全选、复制粘贴和收起保留；
JS 检查中文／emoji 选区替换、删除、过期同步及重复序号。隔离实机记录和退出排查保存在
`.work/official-edit-paths/`。测试进程在收尾时主动关闭 PenChat 并恢复数据，不能把这种退出
记为崩溃，也不能据此排除未复现的偶发退出。


所有机型的共用编辑器支持单击当前折叠光标打开编辑菜单，空字段也可唤出粘贴；
未选中时复制／剪切禁用，空剪贴板时粘贴禁用，双击选词和长按拖动保留。
`tests/test_caret_menu.py` 覆盖 960×266、936×280、640×260、568×1210，
官方编辑定向测试同时覆盖聊天和 Provider 字段。

官方键盘衔接区域使用 `keyboard.field.holeHeight`，在原生完成显示区域调整后确认
透明洞的下边界。聊天的透明洞止于当前输入框下沿，剩余间隙使用主题背景；键盘增高时
可先缩小透明洞，扩大则等待原生确认，避免先暴露尚未准备的黑色底层。系统键盘本身
的配色与底部导航条不修改。Y07 浅色实机对输入框下沿至键盘边界逐行采样验证背景，
完整选区／剪贴板／单次本地发送及保存正文核对记录见 `.work/official-edit-paths/final/`。

## 控制中心的 Page 生命周期去重（0.3.2 开发补充）

部分 Falcon 顺序可能先通知 Page `onHide`，随后才报告控制中心可见；另一些只报告
失焦，关闭时却仍回调 `onShow`。此前前者会进入完整后台清理，后者重复发送前台事件，
可导致抽屉/临时阅读状态被关闭、编辑器重建和不必要的再次准备。

现在 `onHide` 立即让出原生输入，并使用同一只读面板接口与 `$am.getTopApp()` 核对：
控制中心可见且栈顶仍为本 AppID 时保留逻辑页面与轮询，只走焦点交接。隐藏先到时
最多等待 200ms 判断，期间不接收原生输入。其他应用成为栈顶、接口不支持或等待超时
均进入真正后台；实际卸载仍退出原生进程，不能用面板存在屏蔽真实退出。
