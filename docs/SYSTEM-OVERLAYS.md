# 系统控制中心与原生页面交接

PenChat 使用独立 DRM 图层。Y07 的系统控制中心可以在未触发页面 `onHide` 的情况下覆盖
MiniApp，并且 `$am.hasWindowFocus()` 仍然返回有焦点。只启用 `setSupportTopPanel(true)`
会让系统面板在底层打开，原生页面仍挡住显示并继续读取触摸。

## 交接方式

- 启动器复用现有轮询，每100ms最多查询一次窗口焦点和系统面板可见状态，仅在状态变化时发送
  `window.focus`；发送失败保留待交接状态。页面后台后停止轮询，恢复时立即核对。
- 焦点使用系统 `$am` 模块。控制中心可见状态由桥接读取已加载 Falcon 的具名导出
  `_setting_panel` 与 `NWindow::isShowing()`；系统自身 `SettingPanel::bringToFront()`
  使用相同的窗口方法。只读查询，没有对象偏移、固定地址、函数补丁、额外框架实例或系统配置修改。
  符号、对象未就绪时不调用；不使用会逐次输出日志的手势辅助函数。
- 临时覆盖与真实页面后台分开处理。面板出现时禁用原生图层、关闭原生触摸fd并结束当前触摸，
  停止相机/OCR；保留页面、抽屉、草稿、组合拼音、阅读位置及已持有的扫描结果。
  已存在的扫描处理/原图读取继续持有结果，不通过普通注销路径提前销毁。
- 系统面板关闭后恢复原图层和当前页面，重新同步硬件资格。网络接收和数据库保存不会因面板打开而重发。
- 竖屏顶部圆角安全区中的新触摸交给系统手势，不滚动下方聊天。该保护仅处理触摸消息，
  不得拦截滑动尚未松手时到达的面板状态、生命周期或退出消息。
- 真实 Home/后台/退出继续走原有清理路径。内置键盘、裁剪和图片浏览仍保留此前的下拉屏蔽策略。

`system_overlay` 诊断仅记录接口可用性及可见/焦点布尔值，不记录用户内容、窗口截图或凭据。
桥接版本和数据库结构不变。

## Y07 官方输入法的上方页面（dev）

Y07 的官方 IME 会使普通窗口焦点失效，但原页面仍处于显示生命周期内。
原先把“允许保留顶部原生图层”与普通窗口焦点绑定，会隐藏全部 LVGL 内容，
仅留下 Falcon 的灰色输入层。现在使用独立的显示许可：

- 仅当前官方编辑请求接受 `keyboard.layout`；每次有效状态续期750ms。
- 启动器检查页面可见性、控制中心及应用栈顶身份；仅当前应用或本次打开期间
  确认的 IME 所有者可保持显示。其他应用、后台或控制中心使许可失效。
- Native 只呈现实际键盘高度以上的逻辑区域。失去普通焦点时仍可显示这一部分，
  但不恢复原生触摸、扫描或 OCR。桥接停止续期后主动撤下图层。
- 结束编辑时先撤下局部图层，再恢复全屏几何，避免结束瞬间覆盖尚未关闭的系统 IME。
- 保留现有系统确认／取消和输入快照规则，不修改系统键盘。

定向检查：`penchat-input-focus`、启动器39项用例、
`tests/test_official_retained_page.py` 和 `tests/test_editor_overlay.py`，
覆盖失焦、裁切、过期／旧编号、控制中心、后台及取消恢复。

另发现独立的既有选字问题：长 AI 正文覆盖左上菜单区域时，
`test_window_focus.py` 的竖屏导航步骤可能被正文选字接管；该步骤仍待单独修复。
本次官方编辑焦点和生命周期已由新增专项用例覆盖，未将其计为整套回归通过。
