320×240 原始灰度，未接入 UI、OCR 结果或拼接模型的几何输出：

4. 对照组保持独占租约，不让系统 CaptureFrame 在中间重建资源，直接关开采集三次，

旧记录中的子进程退出没有可靠堆栈，本次不据此声称已定位所有退出原因。

## 原因与资源边界

旧实现将 `CVI_SYS_Init`、`CVI_VB_SetConfig` 和 `CVI_VB_Init` 放在同一个进程内
静态初始化中。VI/ISP/VPSS 在每次租约结束时关闭，但 VB 仍保持旧进程的初始化
标记、池索引和共享区映射。系统 CaptureFrame 重建它自己的 VB 共享状态后，
旧进程再次使用这些本地缓存，启动配置成功不代表帧池仍可正确工作。

通过已锁定版本的公开 API 及本地只读反汇编核对，`CVI_VB_Exit` 会释放池、解除
共享区映射并重置本地初始化状态。它与销毁 NN 模型、`CVI_SYS_Exit` 是不同的生命周期。

| 资源 | 生命周期 |
|---|---|
| SDK 依赖组、SYS 上下文 | 扫描进程常驻，不在每次扫描或 OCR 交接时重建 |
| 4KiB ION 锚点 | 进程常驻，避免已确认的最后一次 IonFree 后的供应商 hashmap 缺陷 |
| CVI NN 模型和输入／输出张量 | 保持原来的健康模型常驻策略 |
| VB 配置、池索引和共享映射 | 每次独占采集租约重新建立；VI/ISP/VPSS 和采集描述符关闭后，先 Exit，再交回系统 |
| 灯、笔头 evdev、guardian | 沿用现有租约获取、释放与身份校验恢复 |

本次不新增自动重载、失败重试、缩小原图、临时丢帧或重建健康模型。

## 修复与异常回滚

- 将 VB 配置与初始化移出一次性 SYS 初始化，每个 `CviCapture` 单独拥有。
- 创建进程 ION 锚点后再初始化 VB，VB 初始化未完全成功也走统一清理。
- 析构收尾不抛异常；`CVI_VB_Exit` 缺失或失败时记录明确阶段和返回码，并标记
  本进程 VB 状态不可复用。下一次 `verifyCviCaptureRuntime` 在暂停系统 guardian 前
  就拒绝采集，显示“采集池清理失败，需要关闭并重新打开 PenChat”，不能误当作可安全重开。
- 不调用广域 `CVI_SYS_Exit`，不卸载模型或改写供应商全局变量。

清理失败保护目前通过代码核对，未在真机强制制造 SDK Exit 返回错误。

## 2026-11-09：保留模型与移除旧显示等待（开发修改，待手工复测）

用户再次反馈偶发准备失败和扫描闪屏。本轮代码检查找到以下风险路径；
它们不等于已经覆盖所有偶发故障：

- 父进程仍有旧 CVI VO 方案的显示释放/恢复等待。交回系统采集后，要求
  `/proc/cvitek/vpss` 同时出现 NV12、YUV_400 并稳定三次；四秒超时进入
  `cleanup()`，杀掉扫描进程，也销毁了本来健康的模型。共享内存显示不依赖该条件。
- 旧释放握手等待 LVGL 主线程，增加三秒超时和切页期间的耦合。
- 显示续租间隔约100ms，旧300ms过期窗口只有很小的调度余量。高负载时存在
  透明系统帧暂时直通的风险。这里是代码推断，尚无本次实扫时序证据。
- 取消发生在冷启动或推理中时，原先先恢复系统采集再等待 NPU，存在共享
  SDK 资源重建与未结束推理重叠的窗口。

处理方式：

1. 所有机型默认保持健康模型常驻；切页、键盘、后台及会话变化不关闭模型。
   模型仍在首次扫描准备时加载，之后保留到原生应用进程退出；真正的模型错误
   仍明确报告并使失效上下文关闭，不把失败伪装为就绪。
2. S6 捕获交接保留内部编号确认，但由后台服务直接确认，不再释放显示、等待
   UI 或等待旧 VO 的 VPSS 格式。不再因旧显示等待超时清理子进程；真实 IPC/子进程故障仍按原规则恢复。
3. 先取消并等待本笔处理和模型预热结束，再释放采集硬件并恢复系统 owner。
   保留三秒故障退出界限及父进程租约恢复，避免失联工作进程遗留硬件占用。
4. S6 两端显示保留续租统一为1500ms；输入租约不变。显式后台、隐藏、官方
   键盘和断连继续立即撤回显示，系统覆盖层仍合成在上方。
5. 扫描状态附带 `model_ready` 和原始 `model_prepared_us`，即使硬件已释放也可
   看出模型是否仍健康，以及重新进入是否沿用原预热。

SYS/ION/NN常驻、VB按采集租约重建的边界不变；不保持相机、灯或笔头独占来
冒充模型就绪，不改32/24/8、选帧、拼接几何及丢帧规则。

补充了模型默认常驻、同进程多次 disarm/arm 及显示短暂失联的回归用例源代码。
按用户约定，本轮仅编译和开发包静态校验，不运行这些测试或自动设备验收；
S6反复准备、扫描闪屏和真实纸面效果需由用户继续复测。
