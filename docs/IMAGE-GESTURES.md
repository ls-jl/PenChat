# 图片裁剪与浏览（0.1.56）

照片保存采集帧本身，预览背景不构成图像。图片控件保留解码位图的固有尺寸，
仅使用一个等比变换绘制，不把视口或已缩放尺寸再当作图片大小。
真实暗色内容不会被自动裁边。打开时完整适应可用画布，所有最终裁剪映射回原图像素。

裁剪选框使用独立的画布坐标；单指内部拖动及双指缩放/平移仅变换图片。
四边/四角有22px命中容差，靠近角点可同时调整两边；选框限制在画布与有效图像内，
最小44px，原图在该方向不足44px时允许保留完整细长图。放大最高16倍，并遵守LVGL绘制倍率上限。
“还原”恢复全图选框及初始视图；底部有取消、还原、相册选择和确定，窄逻辑画布分两排。
不保留侧边导航占位、缩放按钮或手动模式按钮。确定仍加入待发送区，绝不因此自动发送。

聊天和归档中的图片使用同一全屏浏览层，只有44px悬浮关闭按钮。
双指以中心锚定缩放并平移，单指拖动，双击切换放大/全图。
图片能完整显示的方向居中，放大方向限制到图像边界；捏合最小临时0.75倍，
松手后用160ms缓动回到适应尺寸，不因只有一个方向小于屏幕而重置。
返回时保留会话、草稿、阅读位置及后台生成。

## 多点输入与资源边界

全部原生页面统一从 Linux evdev 获取 `points` 数组，以触点槽与 tracking ID 保持身份；
第二指不另开手势代次。通过 INPUT_PROP_DIRECT 与 MT 能力发现设备，
O_RDONLY|O_NONBLOCK 打开，绝不 EVIOCGRAB。启动器不注册页面触摸回调。
仅在原生页面前台且未打开官方键盘时读取；每 tick 最多512个输入事件，最多32槽。
打开时同步内核槽状态，若已有手指按下则等全部抬手后接管；
SYN_DROPPED 取消当前手势，丢弃积压事件后同步状态并等待全部松手。
三指或页面生命周期中断取消手势；后台、官方键盘和退出关闭描述符。

原始坐标只根据同一个cfg.json中的tp_direction/tp_xoffset/tp_yoffset映射一次，
屏幕尺寸仍来自width/height；相机工作区的四向变换另由photoPoint处理一次。
图片页通过现有页面级setSupportTopPanel临时禁用下拉面板，防止顶部角点被系统截走；关闭、后台及异常均恢复。
不修改驱动、系统键盘、宿主或设备配置。非图片页面使用同一原生输入，
多指不得造成按键、输入框或上拉新建的误触。

预览解码和相机采集继续使用现有后台及有界缓存；拖动只更新变换与遮罩，不重建页面。
JPEG写入的位累积器改为无符号运算，消除UBSAN发现的有符号左移；
基线和适配摘要见native/camera/stb-adaptation.json，内嵌第三方许可保持完整。
