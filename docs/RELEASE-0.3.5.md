# PenChat 0.3.5 本地发布候选验收

本批从 dev 的 `bc45836` 准备 0.3.5，版本及 package-lock 根元数据同步更新一次。
用户要求全面测试后先保留本地候选包，不上传服务器、推送代码或创建发布。
本记录所列自动化产品检查已闭合；候选仅保存在本地，不合并 main。物理检查边界及一次SDK调试截图事故单独披露，不宣称固件堆问题已修复。

范围包括图片会话命名、常用化学式 `\ce` 原生渲染、DeepSeek 等待／断流处理和
推理强度仪表共同圆心，以及当前积累功能的完整主机、sanitizer、构建和在线设备回归。

在线授权目标为 Y01、Y02、Y07、S6；Y01 初始离线，18:42恢复在线后加入完整矩阵。Y02 不发真实
API 请求；其他设备仅从各自 PenChat 配置读取 DeepSeek 连接，测试使用合成问题、
图片与历史，不发送原用户聊天、图片或草稿。凭据仅在隔离私有文件／临时数据库中使用，
不写入日志或 Git。

设备每个作用域隔离并恢复数据库、设置、私有资产、输入法记录及公共传输目录，核对
宿主 PID 和 boot ID。发现其他任务占用即停止触控并恢复，不重启系统 MiniApp 宿主。
自动传感器测试不等于新增物理纸面扫描质量或真熄屏验收。

原始检查、失败、修复补验、截图、完整候选包与恢复记录保存在忽略目录
`.work/release-0.3.5/`。最终以该目录的验收汇总和包哈希为准。

高倍率长化学式保留原有横向阅读器；主机真实拖动可读到`CO2 ↑`，竖向阅读位置保持不变。

### 诊断流程与测试连接收尾

Y01首轮反馈适配在Home后重开应用时，等待新诊断快照超时；失败现场随后观察到健康的新进程，尚无证据将此超时归为产品崩溃。数值诊断请求现在只对同一个已就绪PID重发可合并的只读SIGUSR2，保留原8秒截止时间；图像请求不重发，PID变化直接失败并保存有界观察记录。反馈测试在物理Home后改用只读焦点／页面／退出证据，不再对非本应用Home场景请求SDK截图。Y01完整反馈适配补验通过：真实30秒限制、按键独占及释放、Home离开和重开、预览与未上传均有记录。

测试用TCP中转的干净EOF用例原来同时关闭连接读写两端，未读关闭帧可能产生RST，导致中转正确报告传输失败。该用例改成半关闭写端，待子进程确认EOF退出后再关闭读端；实际中转实现不变，超大帧仍须失败。新增诊断轮询故障注入覆盖数字请求重发、原截止时间、图像不重发及PID更换拒绝。40项测试监督／传输／观察检查通过，初始EOF失败记录保留。
