## 首轮检查与补修

首轮完整 scanner/native sanitizer 通过。主机截图比较所需 Pillow 不在系统 Python 中，
改用已有隔离 QA 环境 `.work/dpi-merge/venv`（Pillow 11.3.0）；原环境失败记录保留。

完整键盘回归复现了手柄／工具栏覆盖问题：旧夹具先触在“取消”上的不可见扩大区，
这部分应让给按钮；改用实际可见蓝色圆头后，在独立 `bc45836` 基线与候选中仍无法拖动。
现在仅可见圆头优先抓取，扩大区继续让给工具栏，选择菜单仍保留自身优先级。
主机完整键盘回归与四倍率、两方向手柄轮廓检查通过，原始失败和前后诊断保存在
`keyboard-baseline/`、`keyboard-visible-before/`、`keyboard-fixed/`。

S6 首轮启动就绪超时的现场为 `screen_power.known=true, awake=false`，窗口和触摸被
门控，不能算作应用启动后崩溃。数据已恢复；亮屏后资源常驻、面板和设置等检查继续，
启动检查单独补验，不把最初超时改写为通过。

化学式扩展补测发现教材常见的独立 `^`／`v` 放气、沉淀标记会被当成缺失指数；
修复前原生探针明确报 `Missing chemical script`。现转换为上／下箭头，并补齐
`1/2` 这类前置分数系数。原生实际渲染用例扩充为 19 组，覆盖深浅前景色；
原有相邻电荷／同位素上下标语义保留，最终候选和设备截图需包含该增量。
