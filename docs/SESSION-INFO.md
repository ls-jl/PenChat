# 会话信息

在聊天加号菜单中选择“会话信息”。页面沿用深色双列排版；标题与刷新按钮随正文滚动。
查看和刷新在后台完成，不发送模型请求、不修改会话选择，也不清空草稿、图片或聊天阅读位置。
生成结束保存成功后，打开的统计页会更新；生成中可手动刷新快照。手指触摸期间延后应用结果。

## 上下文长度

“当前上下文”复用发送和压缩预算的本地估算器，包括系统提示词、有效压缩摘要、未覆盖的历史、
当前已收到的回复及待发送文字/图片。图片和不透明续传状态使用单独预算，不把Base64当成普通文本。
编辑消息时按截断后的前缀及编辑区图片估算；空草稿下准备重试时不计入将被替换的失败回复。

“最大长度”明确指模型能力设置里的**本地上下文预算**，缺省16,384估算token；并非服务端返回的
模型硬上限。未配置模型时显示“未配置模型”，服务端上限显示“未提供”。自动压缩、重试或继续
编辑后实际发送的上下文可能变化；页面不为了统计请求计数接口，也不自动触发压缩。

## 接口用量

Responses读取响应`usage`，Chat Completions流请求增加`stream_options.include_usage=true`并读取
最后的空`choices`用量块。输入/输出/总token、缓存读取/写入、推理token只接受有效非负整数，
逐字段归一化保存到现有消息`metadata_json.usage`。重复流事件和最终条目只替换计数，不累加。
缺失、null及异常数值不会变成0；明确返回0时保留0。推理token已包含在输出token中。

最近请求显示当前最后一条AI回复的用量，不能借用较早回复的值填补空缺。旧消息和中断请求可能
没有用量；界面显示“未提供”，不使用本地估算冒充接口计费数据。接口拒绝或不支持用量选项时
沿用原有错误提示，不自动重发请求。

缓存命中率为“缓存读取输入token / 对应输入token”。累计使用同时报告两者的回复加权计算，
显示样本数；输入为0时不可计算。它不是请求命中次数比例，也不是请求成功率。

累计只涵盖**当前保留的AI回复**，每个指标分别累计已返回该指标的回复，并显示已收到用量的回复数。
不包含被删除/覆盖的回复、自动命名和压缩请求；复制分支/归档保留消息用量，不能跨会话相加当作
账户账单。页面不估计价格，不宣称账户总消耗。

用量随聊天导入导出保留，只保存上述数字白名单；不包含原始响应、密钥、请求头或加密思考。
不更改数据库表结构、AppID或AMR桥接协议。

## 验证入口

- `penchat-usage-tests`：计数字段归一化、缺失/零/溢出、重复最终事件、请求选项、预算、摘要、图片、流式和编辑预览。
- `tests/test_session_info.py`：两种接口的实际HTTP/SSE、菜单与预设共存、页面、草稿/阅读位置、自动更新、过期结果及重启恢复。
- `tests/native/TransferTest.cpp`：用量导出导入及额外字段剔除。
- `tests/device/display_config.py --serial <serial> --session-info`：ORANGE与113设备隔离目录及本地模拟接口验收，检查真实触摸/截图/两种协议，恢复用户目录且不重启宿主。

字段依据：[Chat Completions流事件](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)、
[Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)、
[token统计说明](https://developers.openai.com/api/docs/guides/token-counting)。
