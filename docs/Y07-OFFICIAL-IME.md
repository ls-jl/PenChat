# Y07 官方输入法代理与默认入口

竖屏官方编辑使用一个真实、透明且可聚焦的 Falcon input/textarea 作为
InputConnection，原 LVGL 字段继续绘制正文。代理保留实际字段边界与最终字体
像素大小；屏幕与触摸坐标保持 Falcon 的逻辑坐标，不再做一次缩放。

代理的 value 仅在打开时设定。后续 input 更新独立的文本缓冲并发送
keyboard.change，不通过 Vue value 属性回写系统当前正在编辑的控件。
同一输入会话保持控件 key、事件处理器及未变化的样式对象，避免删字时替换
InputConnection。关闭或换字段后，旧控件事件由请求 ID、generation 与 token 丢弃。

Y07 的蓝色确认键通过系统 Global.textEditFinished 返回结果，不能只依赖普通
input/textarea 的 confirm 事件。在代理成功显示以后注册一次 startTextEdit，
配置不包含 text，保留代理正在编辑的缓冲。结果按 UUID 匹配，确认保留代理的
最新文本，取消恢复 native 编辑快照；界面清理推迟到回调栈退出之后。
仅面板隐藏不能视为确认，不会因此发送聊天消息或保存 Provider。
横屏继续使用原全屏官方编辑流程。

官方编辑期间 Falcon 根节点保持完整配置尺寸，代理控件透明，video hole 仅覆盖键盘上方的 native 页面区域；
其高度由系统报告的键盘高度从 Falcon 逻辑屏高扣除。键盘及浮动拼音条区域保留
主题实色背景，确保选词后擦除旧像素；整页透明会残影，整页实色则会遮住 native 页面。
native 仅显示键盘上方区域，普通原生输入保持禁用。键盘高度必须有效，失效的显示租约会撤销。
系统键盘本身维持系统外观，不跟随 PenChat 主题染色。

设置 → 键盘与输入 → 默认使用官方键盘，以 app_settings 布尔键
prefer_official_keyboard 保存，缺失或无效类型均为 false。点击后由 DB worker
异步保存，请求 ID 匹配完成结果，期间禁用重复操作，失败保留原值并允许重试。
开启后新建的可编辑字段默认打开官方输入法；取消后同一会话回到内置键盘，
不会自动反复弹出官方输入法。只读文本选择不切换输入法。长按地球的手动入口仍保留。

### 拼音残影与后续定向修复

实机隔离复现：输入 `bi` 再选“比”后，native 与实际绘制文本均从26变为27，
但系统拼音条的 `b` 仍留在 primary 像素中。保持根节点实色后，同一路径选词后
拼音条清空；因此修复显示清理，不增加 getValue 轮询或修改系统候选业务。
过程原图和恢复记录位于 `.work/y07-ime-followup/`。同时修复内置键盘下滑关闭
先归零再退出的问题：直接从现有位移建立退出快照，取消手势仍保留原回弹逻辑。
主机两种竖屏的下滑、取消、多指和后台回归通过，Launcher 48项通过。

余额刷新另固定打开面板时的逻辑坐标锚点，后续刷新和明细触摸不再改变定位依据。
三个布局的本地假传输回归覆盖相同结果刷新边界不变、全提供商刷新、错误结果、
明细、局部滚动及聊天状态保留，不请求真实账户。

内置键盘入场使用约180ms的底部滑入。入场期间发生控件重建时，保存旧根节点的
当前位移，并按剩余距离继续动画，避免重建把键盘突然放到最终位置。普通字段
切换和已完成入场后的局部重建不重复播放整段动画。实际 LVGL 动画测试覆盖位置
连续、最终归零和旧对象清理；下滑收起回归仍覆盖两种竖屏尺寸。

菜单手势按一次完整触摸区分起点：从面板内开始的滚动离开边界仍不关闭；
从遮罩开始的触摸仅在正常松手、仍在遮罩且最大位移不超过12dp时关闭。
拖出面板后松手取消原行点击，防止滚动被误选项；取消、多指及失焦重置跟踪。
此规则共用于厂商参数适配等 choice 菜单和同路径附件菜单。

### 输入框随键盘升起与官方键盘期间阅读

内置键盘滑入时，聊天输入框和回到底部控件使用相同位移与时长一起上移。
键盘重建沿用当前进度，收起或结束编辑清理配套动画，表单字段不额外平移。

竖屏官方键盘期间，仅在有效前台显示租约下为聊天正文开放只读、非独占的原生
触摸观察。手势必须从当时的 reader 区域开始，冻结边界，单指垂直移动超过
现有空间阈值才滚动。该通道不派发 LVGL 点击、键盘、光标、发送、返回或下拉
新建事件；从输入框/官方键盘开始、跨出阅读区、多指、取消及系统面板都终止
或拒绝捕获。返回普通原生输入前关闭 fd，等待旧触点清除。官方表单编辑仍由
系统掌管，不开放这一聊天专用通道。

本轮主机验证包括：两种竖屏输入框逐帧单调上移且不先向下跳、下滑关闭/取消回归、
官方阅读区滚动与键盘起点/多指/系统面板/租约过期/后台隔离。Y07 隔离数据实测
官方键盘保持打开时正文滚动1800→1640，随后退格只修改文本，取消恢复原文本，
没有发送消息；用户数据与宿主身份恢复检查通过。证据在忽略目录
`.work/keyboard-reader-motion/`；正式包仍为0.3.1开发包。

### 收起联动与滚动调度

内置键盘关闭前记录输入框当前可见底边；完成编辑后，从该底边到收起后的底边
播放与键盘退出快照同为180ms的下降动画。下滑松手同样使用当时的位置，
不先将输入框归位。退出期间仍由原快照遮罩阻止点击穿透。

官方阅读区滚动将同一轮 evdev 位移合并为一次 LVGL 滚动，复用已有滚动回调
绘制，不重复调用 paintVisible。文本与光标均未变化的系统心跳不重做编辑布局。
有效官方阅读区也属于可交互状态，主循环按 LVGL 下一次定时器唤醒，不能因
keyboard_ 为真退回50ms非交互等待；实际刷新倍率仍服从已有设置。

本次同一组6次隔离滑动：旧包79个原生绘制帧、平均6507µs；最终包79帧、平均
6333µs，两者均没有超过60Hz的单帧绘制预算。此短测只说明功能与绘制预算通过，
不证明物理FPS或主观流畅度提升。已确认消除逐包重复布局/绘制、无变化光标同步，
并恢复有效官方阅读区的交互定时器调度。日志在 `.work/keyboard-lower-scroll/`。

### 官方滚动惯性、范围与聊天底色

阅读区捕获范围扩展到官方键盘上方的逻辑可见区域，包含侧边留白；起点排除
系统顶边和输入框胶囊。捕获后可以经过原 reader 边界及输入框上方区域，
进入官方键盘区域才结束捕获。键盘/输入框起点仍不接管。

松手速度由最近位移平滑估计，静止超过100ms不启动惯性，使用 LVGL 有界
ease-out 滚动自然减速，不弹性越界。再次触摸、取消、多指、键盘高度变化、
系统面板、后台或退出官方键盘均终止惯性。

输入框外侧和官方代理底板均跟随当前页面主题背景，不单独指定黑色或白色。
原生页面与 Falcon 衔接层使用同一主题背景；顶部透明窗口和拼音条擦除机制保持不变。

Y07 浅色隔离验收：侧边x=8起拖越过旧reader下边界，松手后设备端连续采样
scroll1434→1331，确认存在后续惯性位移；再次触摸停止，文本保持不变。
原生输入框外侧与官方衔接区黑底截图已检查。首次主机往返读取太晚，已保留其
失败记录并改成设备端紧接释放采样，不将读取时的静止误报为没有惯性。
原数据与系统宿主身份恢复验证通过。证据保存在 `.work/official-inertia/`。

用户随后明确要求保持页面背景：已撤回上一批强制黑底及 canvasColor 覆盖，
不改变惯性、扩大触摸范围或键盘升降联动。上面的黑底截图仅是旧候选的历史记录。

### 胶囊外圈透出实际页面内容

用户进一步明确外圈必须透明，而不是填相同背景色。停靠编辑时 reader 不再
裁在输入框上沿，改为延伸到键盘顶边，聊天内容保持在胶囊下方绘制。只有胶囊
本身保留底色，外圈露出实际页面。底部 padding 同步增加被胶囊遮挡的高度、
停靠间距和原安全留白；新增 viewport 高度与 padding 配对，保持滚动范围与
末行可达性，不以整条背景区域替代透明。该规则同时用于内置和官方停靠键盘，
表单不改成浮动 reader。主机断言覆盖旧消息延伸到胶囊后方、末行位于胶囊上方
至少16dp、两种竖屏升降、下滑取消及官方惯性。产物在 `.work/composer-transparent/`。

### 深浅主题动画、稍宽胶囊与下沿截断

竖屏胶囊左右各减少4dp留白，总宽增加8dp；通过 UiMetrics 解析，横屏尺寸不变。
聊天 reader 保持完整绘制范围，键盘占用改由稳定的底部 padding 预留，避免动画
开始时先裁到最终高度而露出一条底色。胶囊底边下方的非交互遮挡是胶囊的子对象，
随高度、位置和动画一起移动；圆角外侧仍透出聊天内容。绘制扩展范围显式注册给
LVGL 9.6，不依赖 overflow 标志自动扩大绘制区域。遮挡不参与按钮排列或点击。

`test_composer_motion_pixels.py` 使用浅/深主题、Y07圆角安全布局和长代码块背景，
分别采集17帧（含打开、收起中间帧）。采样圆角像素必须等于后方内容颜色，底边
以下采样必须为页面背景；两主题均通过。逐帧截图与联系表留在
`.work/composer-theme-motion/`。平台布局测试覆盖75/100/125/150%的dp规则；
升降连续性、下滑取消、官方滚动及页面保留的定向回归通过。主机帧检查不等同于
对实体LCD每一帧的测量；本批仅进行开发包安装校验，没有执行全量回归或发布。

### 下圆角的最终状态规则

键盘打开以及尚未完成收起时，下方遮挡延伸到两个下圆角外侧；重新描绘胶囊
下半圆弧后再绘制按钮，避免覆盖输入框本身。键盘完全收起后，不再绘制该遮挡，
包括下圆角、下沿和两侧在内的整个外圈都恢复透出后方页面。遮挡使用绘制阶段
状态判断，不在绘制回调中修改控件布局。深浅主题各17帧检查覆盖打开、收起中
和完全收起，均通过。上述早期“始终截断下沿”仅为历史实现记录。

历史菜单按钮改为“新聊天”。底栏按实际字体测量，竖屏一行放不下时使用两行，
保持文字完整和设置右对齐；扫描状态为就绪、准备中、不可用的最大实测宽度
预留空间，字号与高度均取实际字体。主机覆盖字号125/150及界面150+字号150，
并保留两种横屏回归。截图位于 `.work/portrait-chat-header/`。
