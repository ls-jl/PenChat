# Y07 官方输入法代理与默认入口

竖屏官方编辑使用一个真实、透明且可聚焦的 Falcon input/textarea 作为
InputConnection，原 LVGL 字段继续绘制正文。代理保留实际字段边界与最终字体
像素大小；屏幕与触摸坐标保持 Falcon 的逻辑坐标，不再做一次缩放。

代理的 value 仅在打开时设定。后续 input 更新独立的文本缓冲并发送
keyboard.change，不通过 Vue value 属性回写系统当前正在编辑的控件。
同一输入会话保持控件 key、事件处理器及未变化的样式对象，避免删字时替换
InputConnection。关闭或换字段后，旧控件事件由请求 ID、generation 与 token 丢弃。

Y07 的蓝色确认键通过系统 Global.textEditFinished 返回结果，不能只依赖普通
input/textarea 的 confirm 事件。在代理成功显示以后注册一次 startTextEdit，
配置不包含 text，保留代理正在编辑的缓冲。结果按 UUID 匹配，确认保留代理的
最新文本，取消恢复 native 编辑快照；界面清理推迟到回调栈退出之后。
仅面板隐藏不能视为确认，不会因此发送聊天消息或保存 Provider。
横屏继续使用原全屏官方编辑流程。

官方编辑期间 Falcon 根节点保持完整配置尺寸，代理控件透明且不创建 video hole；
根节点保留主题实色背景，确保系统浮动拼音条在选词后能擦除旧像素（透明根背景会留下残影）。
native 仅显示键盘上方区域并释放触摸 fd。键盘高度必须有效，失效的显示租约会撤销。
系统键盘本身维持系统外观，不跟随 PenChat 主题染色。

设置 → 键盘与输入 → 默认使用官方键盘，以 app_settings 布尔键
prefer_official_keyboard 保存，缺失或无效类型均为 false。点击后由 DB worker
异步保存，请求 ID 匹配完成结果，期间禁用重复操作，失败保留原值并允许重试。
开启后新建的可编辑字段默认打开官方输入法；取消后同一会话回到内置键盘，
不会自动反复弹出官方输入法。只读文本选择不切换输入法。长按地球的手动入口仍保留。

## 定向验证与证据边界

主机检查覆盖默认/错误类型、异步失败重试、重复保存、重启恢复、横竖屏聊天/
普通字段/密钥字段、只读选择，以及官方文字镜像、失效租约、旧 ID、取消和确认。
JS 检查覆盖稳定代理值、控件身份、字段字号、系统结果 UUID 和延后清理。

设备定向测试使用私有假数据，隔离并恢复数据库、设置、资源和公共导入导出目录。

Falcon 方向、完整图及单独键盘区域，避免长图预览漏显示下半部分而误判黑屏。
这些图片证明对应 surface 的像素状态，不能替代实体 LCD 的人工体验验收。

### 拼音残影与后续定向修复

实机隔离复现：输入 `bi` 再选“比”后，native 与实际绘制文本均从26变为27，
但系统拼音条的 `b` 仍留在 primary 像素中。保持根节点实色后，同一路径选词后
拼音条清空；因此修复显示清理，不增加 getValue 轮询或修改系统候选业务。
过程原图和恢复记录位于 `.work/y07-ime-followup/`。同时修复内置键盘下滑关闭
先归零再退出的问题：直接从现有位移建立退出快照，取消手势仍保留原回弹逻辑。
主机两种竖屏的下滑、取消、多指和后台回归通过，Launcher 48项通过。

余额刷新另固定打开面板时的逻辑坐标锚点，后续刷新和明细触摸不再改变定位依据。
三个布局的本地假传输回归覆盖相同结果刷新边界不变、全提供商刷新、错误结果、
明细、局部滚动及聊天状态保留，不请求真实账户。

内置键盘入场使用约180ms的底部滑入。入场期间发生控件重建时，保存旧根节点的
当前位移，并按剩余距离继续动画，避免重建把键盘突然放到最终位置。普通字段
切换和已完成入场后的局部重建不重复播放整段动画。实际 LVGL 动画测试覆盖位置
连续、最终归零和旧对象清理；下滑收起回归仍覆盖两种竖屏尺寸。
