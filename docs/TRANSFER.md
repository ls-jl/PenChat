# PenChat 0.1.22：导入与导出

首次启动建立 `/userdisk/Favorite/PenChat`，每次启动补齐 `导出/聊天`、`导出/预设`、
`导入/聊天`、`导入/预设` 和 `使用说明.txt`。Falcon 没有应用安装回调，因此未启动
应用时不会预先建立目录。创建失败只提示，不影响聊天。主机测试使用私有测试目录。

设置 → 导入与导出。历史会话长按菜单中的导出可直接选中当前会话。聊天支持单个、
跨页勾选和全部（含归档）；预设包括默认预设。文件放入对应导入目录后刷新列表，
预览、选择项目后导入。源文件保留，不自动移动或删除。

设置中的“持久化导出目录”默认开启。关闭后，正常退出原生进程时清理
`/userdisk/Favorite/PenChat/导出`，保留导入文件和说明。切后台、打开键盘不会清理；
下次启动补齐导出目录。清理前先取消并等待传输任务，保存最新聊天；可见目录原子
移入私有临时区后回收，以适应宿主退出时限。清理失败会在下次启动提示。强制断电
或 SIGKILL 无法保证立即执行退出清理。

## 格式版本 1

聊天是标准 ZIP，扩展名 `.penchat.zip`；UTF-8 文件名由标题、毫秒时间、短随机标记
构成。包内含 `manifest.json`、`conversations/*.json`、`markdown/*.md` 和 `assets/*`。
清单标记 `format=penchat`、`version=1`、`kind=chats`、应用版本、会话索引及每个文件
的实际字节数和 CRC32。CRC32 用于损坏检测，不提供签名或身份认证。

会话保留标题、顺序、角色、时间、状态、正文、公开思考/耗时、图片、配置和归档/
置顶状态。Markdown 使用相对图片引用，解压即可阅读。相同资产 ID 在包中复用。
不含数据库、密钥、认证头、日志或加密续传条目；导入后从普通历史继续聊天。
空会话、草稿与未发送图片不导出。回复仍在生成或内容未保存时提示稍后再试。

预设为 `.penchat-presets.json`，同样带独立格式版本，`kind=presets`。模型使用名称、
Provider 名称、去凭据的地址和接口类型描述；不以本地 ID 作为跨设备关联依据。
能力模板和 Provider 凭据不导出。未知模型描述保留，导入时标为待配置。

## 导入规则

- 导入新建 ID 与关联，保留原会话、草稿、阅读位置和全局默认配置。相同来源与校验
  标记默认跳过；可明确另存副本。源会话的新内容作为新副本，不自动合并。
- 模型只在地址、接口类型、名称唯一准确匹配时绑定，也可在预览中选择本地模型。
  未匹配保留待配置，不自动建立 Provider。预设应用时继续检查推理强度兼容性。
- 普通预设同名时添加“导入”后缀；默认预设默认准备替换，必须另行勾选确认，
  也可选择普通副本或跳过。替换不追溯已有会话，不自动开启预设入口。
- 普通 Markdown 作为一条助手参考消息，标记“导入的参考内容”，不自动调用模型。
  标准行内图片 `![说明](子目录/图片)` 从导入目录安全复制。越界/缺失图片显示
  不可用；HTTP(S) 图片保留为链接，不下载。导入的本地图片可再次随聊天包导出。

## 后台与边界

独立任务线程读取、校验、复制文件；数据库的 SQLite backup API 建立私有一致性
快照，快照不会进入成品。任务期间租用资产，避免被回收。大文件复制使用 64KiB
缓冲，校验实际字节数、CRC、剩余空间与安全路径；拒绝符号链接、绝对/越界路径、
重复条目、未声明文件和加密 ZIP。不调用系统压缩命令。

目前限制：单包实际解压合计不超过 512MiB，最多 10000 个文件、2000 项会话，
单个 Markdown 与整包 JSON 文本合计各不超过 32MiB，JSON 嵌套最多 64 层、
解析事件最多 100 万次；单会话导出正文与思考合计不超过 16MiB。
超限明确报错，建议分批导出。取消检查发生在文件块/条目之间；已开始的数据库
原子提交完成后才返回。数据库事务失败清理本次准备的资产。退出清理临时目录，
异常退出的残留在下次启动清理。文件保留在私有任务目录，完成后以原子链接发布，不覆盖。ORANGE 的数据与导出
目录在同一分区；跨分区配置会明确拒绝发布，不留下半个成品。

复用现有表与元数据存储导入来源和模型描述，不升级表结构。ZIP 依赖 miniz 3.0.2
锁定源码提交与 SHA256，许可证随生产包分发。
