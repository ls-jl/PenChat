# Y07 相机预览流水线优化（dev）

用户自行进行效果测试；此轮不跑主机回归、真机自动化、截图验收或帧率基准，不做Release。
仅编译、执行安装包的身份／内容校验后安装。以下为代码路径分析及改动，不是实测性能结果。

## 已移除的重复工作

- 普通预览不再每帧复制完整NV12到连续内存；直接从已出队、尚未归还的V4L2 planes
  按真实stride转换，完成后立即归还。真正保存照片时仍复制完整原始像素，高清链路不缩小。
- 根据旋转后的原始比例和实际预览区域计算显示尺寸，不先生成720×960再交给LVGL缩小。
  区域来自公共布局和Falcon逻辑尺寸，不写死屏幕分辨率；已有非Y07预览上限保留。
- 使用三份只读共享预览缓冲，只有未发布、无人读取的对象才允许复用。显示中或待显示
  的对象不改写；相机线程退出时释放池，只保留UI尚在使用的有效引用直至页面销毁。
- 四缓冲采集至多追赶三份旧预览，优先处理最新画面，避免转换较慢时回放队列。
  仅作用于拍照预览，不改扫描的有序帧规则，不丢弃正在处理的高清照片。
- NV12转换保留原最近邻映射和YUV公式，按轴预计算坐标，去掉逐像素整数除法；
  90°／270°采用16×16分块访问，减少跨整列访问源图时的缓存浪费。
- 预览使用不透明XRGB描述，避免无用Alpha混合。UI约33ms检查一次新画面，取消原60ms
  软件上限；同一帧不反复更新图片、缩放、位置和空状态文本。采集端保留30ms节奏余量，
  避免30fps传感器的32／34ms轻微抖动导致隔帧拒绝。
- 拍高清照片时不再额外制作一份仅供短暂显示的BGRA缩略图，保留上一份有效预览直到
  高清保存完成进入裁剪页。快门角冻结、HD尺寸、方向校正、裁剪与相册行为不变。

## 尚待用户确认

实际预览流畅度和延迟、旋转显示、高清拍照与裁剪、连续进出及相机退出资源释放。
不承诺某个实测FPS；约30fps是软件调度目标，实际取决于采集、转换及显示耗时。
