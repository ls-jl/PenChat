# dev：Y07 圆角安全区与底部输入

沿用 Falcon 逻辑尺寸、旋转与原生触摸映射，不改变设备分辨率配置。
本轮不升版本，不发布、安装或推送。

## 布局

- `AppLayout` 集中提供竖屏安全边距。当前 Y07 568×1210 下，左右及顶部
  留24px，底部28px；更宽竖屏按短边计算并限定留白范围。横屏原几何不变。
- 聊天胶囊、回底按钮、菜单按钮、扫描状态、业务页返回／页头操作、
  历史抽屉首尾与图片查看关闭按钮使用同一安全边距。
- `EditorLayout` 区分按键可用宽度与屏幕／编辑区宽度，按键与触摸命中
  区一起内收。字母键高度保持原值，Y07可操作区域仍不少于44px。
- Y07所有普通输入改为底部弹出，原页面保留在上方；读取区随键盘缩短，
  能继续滚动，输入期间遮住其业务点击，避免误保存或误切页。
- 聊天直接在键盘上方的圆角聊天框编辑，提供发送箭头；“收起”只回填
  草稿，不发送。直接发送仍走原有校验、上下文准备和请求流程。
- 其他字段在底部显示字段名与紧凑编辑区，“完成”回填、“取消”恢复。
  Provider仍需明确保存；打开键盘不保存配置。
- 候选展开、剪贴板和文本菜单可覆盖阅读区，键盘不移动。只读消息选区
  页面仍是独立阅读任务，手动官方键盘仍由系统显示。

## 状态与资源

复用现有独立拼音、学习、OCR、绿色光标、拖动／选区、撤销及官方键盘
确认／取消协议。输入会话独立，取消不改写原值；完成回调只执行一次。
底部面板缩放阅读区时保护滚动状态；结束或切页释放输入遮挡控件。
不新增数据库字段、系统输入协议、第三方运行库或输入词典。
