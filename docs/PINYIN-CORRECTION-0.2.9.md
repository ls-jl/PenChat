# PenChat 0.2.9：适度放宽纠错

## 调整

0.2.8遇到完整有效拼写会跳过纠错；0.2.9仍尝试补充覆盖全部原码的纠错词，最多2项。
前两个完整正常候选保持原位，然后插入最多2个纠错候选；其他正常候选保持原相对顺序。
没有完整精确解释时，继续沿用最多8项补充的上限。

- `niao` 保留“鸟、尿”，也能选到“你好”。
- `tiajia`、`tiannjia` 可选“添加”；`chengong` 可选“成功”。
- `xuxi` 可选“学习”，`xiaohang` 可选“校长”。
- 原始拼音、Enter原码、Space正常首选及取消不学习保持不变。
- 仍仅纠正一次编辑、4～32字母，不跨显式分隔符，不新增模糊音或两处错误猜测。
- 保留现有开关、蓝点/长按说明、候选版本校验；不修改数据库结构或AMR桥接。
  词典和音节表仍为1,253,849字节。

## 回归与测量

40条固定人工错拼样例的前五命中：关闭11/40，0.2.8为28/40，0.2.9为40/40。
首选仍为27/40：此次优先让用户能选到纠错词，不通过改写正常首选提高这个数字。
固定样例不代表通用语料准确率。

正常26键样例首选70/73、前五73/73；九宫格首选62/70、前五67/70，保持原有命中。
完整正常候选的前两项保留；九宫格前48项逐项一致。26键完整列表有意增加纠错项，
不再要求全部候选逐项相同。

113设备同批交替9轮、未锁定DVFS，热查询排除词典加载、35ms合并和UI绘制：

| 指标 | 结果 |
|---|---:|
| 正常26键P95，关闭→开启 | 2.733→3.164ms（约+15.8%） |
| 错拼查询P95中位数 | 5.199ms |
| 正常查询峰值RSS中位数，关闭→开启 | 13,592→13,592KiB |
| 固定错拼集最大状态扩展 | 5,046次，上限16,384次 |

正常与错拼热查询P95均低于20ms。与0.2.8相比，需要为有效拼写也执行有界搜索，
因此增加少量计算时间；保留35ms合并窗口和单工作线程，不增加UI同步等待。
