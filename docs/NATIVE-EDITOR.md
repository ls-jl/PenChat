# PenChat 内置编辑器

所有输入字段复用独立编辑会话。取消不回写，完成只调用一次原字段回调；聊天完成编辑不等于发送。

## 键盘与布局

ORANGE 使用960×266逻辑坐标。左侧前三行64px，底行44px；底行依次为123/ABC、逗号、
经纬线地球键、拼音/English空格、句号、Enter。数字/符号页第三行左键互相切换，ABC总是
回字母，下次123总是进入数字。中英文和字母Shift状态独立。

底行宽度依次为68、64、64、192、64、104px，键间距4px；逗号、地球和句号等宽。
中文模式的逗号、句号、问号、感叹号、冒号、分号和括号使用中文标点；英文及密钥使用英文标点。

右侧候选位于顶部，正文为592,78,360,130。底部214px操作行为取消、官方、单行/多行、完成、剪贴板。官方64px、扫描48px、完成104px、剪贴板44px，间隔4px，均44px高。
密钥显隐位于候选区域；隐藏状态不允许复制/剪切，显式显示后复制只进入临时当前槽，不进入历史列表。

## 触摸与编辑

点按定位、双击选择英文单词或中文字符，emoji连接、修饰、变体及旗帜组合保持在同一边界。
选区两端原生拖柄支持调整和交叉；长按450ms后拖动移动光标，普通拖动滚动正文。
无选区静止长按松手在落点附近出现悬浮编辑菜单：无剪贴板内容时为96×52px撤销，有内容时为188×52px撤销/粘贴，不绘制整行遮挡背景、不改变编辑区尺寸或滚动位置；点按菜单外的正文关闭。长按选区出现单行悬浮全选/复制/粘贴/剪切菜单。
0.1.49起，选区拖柄始终锚定真实文字端点，允许越过输入框及键盘分界；菜单与放大镜只按物理屏幕避让，
不再挤回编辑区。跨到字母键上方的菜单优先接收点击，屏幕右边缘的放大光标仍与原光标同列。撤销保留最近20步，
包括正文、拼音、光标和选区。滚动或触摸取消会中断双击判定，官方取消恢复原正文滚动位置。文本与选区内部使用Unicode字符索引，官方桥接才转换UTF-16。

拖动不重建键盘，异步候选延后重建，OCR插入延后到当前触摸释放；后台和取消停止重复按键。
应用内剪贴板共享于各字段，最多20条/512KiB，去重并淘汰最旧记录，不落盘、不进入日志。
输入长度超限明确提示，不截断粘贴或扫描内容。

## 独立拼音（0.2.1）

内置拼音使用源码锁定的 libpinyinime，由原生单一后台线程管理分词、候选与精确拼音。
不加载 Falcon 拼音模块、不解析系统解码符号、不接触系统或官方用户词库。
官方按钮只在主动选择时打开系统编辑器，OCR、触摸与生命周期桥接独立保留。

主布局为26键拼音、26键英语、九宫格拼音，数字/符号页与主布局独立。
普通点击地球在常用中文布局和英语间切换；不足2秒且没有输入或正文修改的连续短按，
按26拼音→英语→九宫格→26拼音轮换。长按450ms直接选择，长按不触发短按。
实际拼音输入更新常用中文布局；只浏览布局不改变偏好。首次为26键，英文专用字段默认英语。

中文布局各自暂存组合与精确筛选状态。空格选词，回车只上屏原始字母或九宫格数字，
完成先处理当前组合；结束时直接丢弃其他暂存组合。官方取消恢复全部状态，确认直接完成。
九宫格上方三行使用标准分组，1键打开标点，左侧筛选精确拼音，底行为数字、地球、空格、删除、回车。

本地请求携带编辑会话、布局、请求序号和候选版本。35ms合并，最多一个在途查询；
选择操作保留顺序，触摸期间延后渲染，旧结果不得改写新输入。超过128字节的组合保留原文，提示分段输入。
库适配公开原码消费位置和候选拼音；查询/选择不直接改写学习数据。基础词典只读。

学习默认开启，26键与九宫格共享常用词与新词；仅完成编辑后提交仍在正文中的选词记录。
取消、原码、粘贴、OCR及密钥不产生学习。私有 `ime/user.json` 上限10000条/2MiB，超限按最近使用淘汰，
以临时文件、fsync、原子替换保存。损坏文件保留，写入失败只提示不撤销已完成输入；不进入诊断、Git或聊天导出。
设置→键盘与输入可暂停学习或确认清除记忆，关闭学习不会隐藏已学词。

## 系统桥接

- `editor.state {session, sequence, active}` 管理页面级控制中心开关；启动器返回
  `editor.policy {session, sequence, ok, blocked}`。序号单调递增，旧策略不覆盖新编辑会话。
- `ocr.start {requestId, session, mode:single|multi, continuous:true}` 在原生扫描租约释放后注册
  系统OCR。每次笔头划扫产生`ocr.status`及带`capture`编号的`ocr.result`，结果只接收一次。
  对应`ocr.cancel`注销监听并恢复系统扫描标志。无明确划扫起始信号的固件不启用连续OCR。
- 单行结果直接入框，多行各次扫描按换行连接；单行字段以空格连接。切换模式会使旧请求失效。
  系统返回文本不再经过旧的API Key猜测/去空格逻辑，用户在编辑区核对后确认，Provider仍需保存。
- 内置编辑器使用`$page.$npage.setSupportTopPanel(false)`；完成、取消、后台、异常和销毁恢复。
  官方键盘开启前停止OCR并释放原生策略，由官方管理自身页面；官方取消后恢复原生策略和编辑状态。

## 验证入口

`tests/test_keyboard.py`运行真实原生进程，覆盖键位、异步拼音、OCR乱序去重、选区、剪贴板、
官方切换、长文本和生命周期，截图输出`.work/keyboard/`。
`npm run test:device:keyboard`先关闭无待确认内容的应用，隔离整个私有数据目录及公共导入导出目录，
再用未保存的Provider表单检查真实触摸、拼音、选区、剪贴板和官方切换，连续开关编辑器20次。
结束后逐文件校验并恢复原目录，不重启宿主。异常中断时保留`*.keyboard-acceptance-saved`，
下次运行拒绝覆盖，先恢复备份。
真机控制中心下拉、扫描租约与物理纸面OCR需要分别验证，注册成功不等于识别质量验收通过。

### 拼音纠错（0.2.9）

“设置 → 键盘与输入 → 拼音纠错”默认开启，仅为26键补充错键候选。
蓝点表示纠错，长按候选可查看正确拼音；原始拼音始终保留，Enter仍输入原字母。

### 第二行边缘热区（0.2.10）

返回手势吞掉；完整侧滑仍可取消编辑。热区仅在键盘内，九宫格和数字符号页不扩展。
