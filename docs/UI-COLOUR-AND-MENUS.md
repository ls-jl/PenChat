# 公共配色与悬浮菜单（dev）

页面画布统一纯黑；卡片、字段、弹层和键盘保留独立角色。`theme.hpp`
集中管理普通表面、主操作、禁用、选中、正文、思考、链接与危险操作色。
键盘内部的旧灰阶和几何保持不变；页面背景不能再通过当前 view 名称
隐式改写任意嵌套控件。主按钮与已选项分开：主按钮近白底深字，非键盘
已选项使用蓝色原生勾选标记，禁用项使用固定前景和背景，不靠整体半透明
将白色按钮混成另一种亮灰。

长按消息、历史等操作采用小地球菜单的深色、细边框和圆角，面板大小由
内容及可用区域决定，最多占可用高度80%。历史操作改为纵向列表，列表
内部可以滚动；菜单打开时高亮对应历史行，不重复展示标题和时间。复制/粘贴菜单保持
横排及既有选区避让，只统一样式。删除、重试确认和普通选择器保留结构。

Y07 打开加号保留原位编辑、光标、未上屏拼音、候选、撤销和 OCR 会话。
第一次点击菜单外只关闭菜单并消费整次触摸；第二次点击键盘才输入。
模型、强度及预设选择保留编辑会话；跳转拍照等独立页面时才正常完成
原编辑。圆角避让按设备能力与 Falcon 逻辑几何计算，主机可独立注入
Y07 圆角测试能力，设备构建不包含该注入入口。

块级代码只铺一次代码背景；行内代码继续使用独立底色。消息原文、
Markdown 换行、复制偏移和数据库结构均不改变。

定向入口：`penchat-popup-style-tests`、`penchat-markdown-wrap-tests`、
`penchat-text-selection-tests`、`tests/test_ui_theme.py`。主机截图、键盘
改前改后对照和验证日志留在忽略目录 `.work/ui-unification-20261113/`。
三类布局使用虚构数据；主机截图不代表真实设备的触摸或物理圆角验收。

Y07 加号外触摸吞掉及模型切换保留组合均通过。历史时间与文本菜单
定位回归通过；popup-style、markdown-wrap、text-selection 三个原生用例
通过。三类键盘在空组合、输入组合、小地球菜单三种状态下，与改前
截图逐像素一致。AArch64/ARMv7 开发包编译及身份、架构、资源校验通过。
