# 上滑新建灵敏度 · 0.2.3

设置 → 阅读与交互 → 上滑新建灵敏度。偏移范围 −25%～+25%，默认 0%；
正值更灵敏，负值更稳。滑条只预览，保存后生效，取消不改变设置；
“恢复基准”把待保存值设为 0%。关闭进程后保留已保存的偏移。

新版基准为上一版灵敏度的 85%。以 208px 可阅读区域为例，拉满距离由
142px 增至约 167px（12px 起步 + 155px 填充）。距离按以下规则计算：

```
round(142 / (0.85 × (1 + 偏移 / 100)) × 可阅读高度 / 208)
```

可阅读高度排除静止输入胶囊、裁剪和上拉位移。使用 Falcon 已旋转、偏移映射的
逻辑坐标；不再按触摸屏物理分辨率重复缩放。指针按下时冻结几何与偏移。
偏移仅调整进度拉满距离，起步、横向排除、慢拉、防误触 500ms 和平滑回弹规则不变。
新设置使用 `pull_sensitivity_offset`，无数据库结构或桥接协议变更。

设置页在“阅读与交互”的字体与键盘行之后增加一行左列入口；数据与应用分组顺延。
设置首页仍为同一个滚动区，开关或选择器返回时保持位置。
