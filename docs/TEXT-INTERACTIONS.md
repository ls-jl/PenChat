# 文本选择与编辑交互

当前开发版保持 0.2.34。此功能不修改数据库正文、表结构、网络协议或 AMR 桥接。

## 使用方式

| 手势 | 编辑中的输入框 | 只读正文／选择文本页 |
|---|---|---|
| 单击 | 定位光标，取消原选区 | 取消已有选区；无选区时保留链接等原点击动作 |
| 双击 | 选择英文单词、中文字符或完整组合字符 | 同左 |
| 静止长按 | 先显示选词反馈，松手后显示菜单 | 同左 |
| 长按后拖动 | 移动光标，显示放大镜 | 从按下处扩展选区 |
| 拖动选区手柄 | 调整范围，允许端点交叉 | 同左 |
| 长按成立前拖动 | 滚动，当前手势不再转为选字 | 同左 |

长按为 450ms、双击窗口 350ms、移动容差 12 个屏幕逻辑像素。短横屏编辑器只对文字命中做反向缩放，不再缩放手势阈值。触摸取消恢复本次临时调整，不执行菜单动作。

编辑菜单提供全选、复制、粘贴、剪切、撤销，不可用项禁用；空输入也可使用粘贴或撤销。只读菜单只有全选、复制，不启动键盘或 OCR。复制后保留选区。隐藏的密钥禁止复制和剪切；显示后的复制不写入普通多条剪贴板历史。

自己的已发送消息保留“复制、选择文本、编辑消息”长按菜单；选择文本仍打开独立页面。AI 正文直接原位选择，下方全文复制、重试、分支图标不变。全文复制保留原始 Markdown；局部复制使用可见文字，不加入排版折行，表格使用制表符分列，代码保留空白，公式作为完整 LaTeX 单元，图片不进入文字选区。

## 实现边界

- `text_gesture.hpp`：共用手势状态机，滚动、光标拖动和范围拖动在一次手势中锁定模式。
- `app_keyboard.cpp`：继续复用 EditorState、撤销及应用内剪贴板；独立只读选择页也复用此状态。
- `app_text_selection.cpp`：显式注册只读区域、原生标签／富文本命中、选区与浮层，以及链接延迟导航。
- `markdown.cpp`：按需生成与原排版一致的文字命中矩形。仅活动区域的可见块保留命中缓存，退出选择释放缓存。
- 区域以对象和递增身份注册，删除回调注销；不遍历并接管所有标签。按钮、开关、候选词和历史列表行保留业务手势。多段 AI 回复是一个选择区域，思考内容独立。
- 只读覆盖聊天和归档正文、思考、网页正文／地址、摘要、信息详情、导入预览、导出路径、格式规范、更新说明、反馈诊断、错误详情及关于等明确注册的阅读区域。
- 菜单、手柄和放大镜使用浮层，不挤压正文；避让屏幕及安全边界不限制真实光标命中。
- 可选择链接单击延迟 350ms；双击、长按、选区存在或生命周期中断时取消导航。
- 选择期间保持排版快照，网络与持久化继续；退出后应用最新内容并保持阅读位置，不自动恢复底部跟随。动态标签恢复选字期间收到的最新状态。
- 编辑触摸与只读触摸在按下时确定归属，跨区域拖动不接管对方手势。后台、切页、弹窗关闭和对象销毁撤销手势及待执行链接。
