# Y07 圆角安全区（dev）

共享 `ScreenSafety` 使用已解释的 Falcon 逻辑尺寸和明确的 Y07 能力；其他
机型不因纵横比或分辨率获得此遮罩。短边 S 的保守半径为 ceil(0.20S)，
额外余量为 ceil(0.015S)。它来自用户照片估算，仍非面板厂商规格。

边缘控件按整个矩形最靠近上下边缘的位置计算圆弧横向内缩；顶部和底部
基础操作区至少保留 ceil(0.08S)。页面正文中部不增加通栏侧边距，滚动页
末尾增加必要留白。背景、预览和图片画布继续铺满，未改变图像像素处理。

适用范围：聊天顶部菜单／标题／扫描状态、输入框底部余量、历史抽屉，
业务页面标题和动作、弹窗底部按钮、扫描结果确认、相机底部操作、裁剪
确认、图片关闭、引导页，以及选择菜单、小地球菜单和放大镜。扫描结果
查看和普通图片查看复用相同安全位置。

键盘中部字母键和候选区保留原几何。底部地球与收起按钮共同避让，保持
对称和同一基线；扩展命中区可延伸，但有完整可见操作区域。选区手柄
仍可部分出屏；放大镜的安全位置绝不用于限制光标或选择范围。

菜单可用高度与物理屏幕高度分开：键盘上方空间仅限制弹层的下边界，
不会把键盘顶边误当作物理圆角。公开协议、数据库和扫描算法没有变化。

定向检查使用 `penchat-popup-style-tests`、已有平台布局／放大镜／文本选择
用例、`tests/test_rounded_screen.py` 与 `tests/test_ui_theme.py`。主机截图及
用于目视检查的圆角遮罩保存在忽略目录 `.work/y07-rounded-20261113/`；
遮罩不加入设备显示层，模拟相机／扫描不代表硬件画质或物理圆角验收。

本轮四个原生定向用例、Y07 实际控件边界与七页引导检查、三类布局菜单
回归通过。18 张主机截图已配保守圆角遮罩检查；扫描使用模拟工作进程。
未启用该圆角能力时，三类键盘的空组合、拼音及小地球菜单共九组截图
与修改前逐像素一致。两架构开发包通过身份、资源及架构校验。
未运行全套发布回归、sanitizer 或自动真机手势验收。
