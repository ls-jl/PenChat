## 全部九键音节固定后的部分选字（0.3.2 开发修复）

用户反馈的 `4685426 → gou → jian → 构` 已在当前真实词典测试中复现：旧结果
consumed=4、remaining=426、fixed=ian，与反馈描述一致。全部音节固定后，传给
解码器的是普通拼音 `gou'jian`；解码器返回带分隔符的位置，外层却按原数字串消费，
因此多删除一个数字及一个后续拼音字母。

现在在生成九键候选时将这种完全拼写输入的消费位置转换为数字数量，再统一用于
候选详情、剩余数字和剩余固定音节。混合拼音/数字的过滤及 26 键原始拼音位置保持
各自语义。选“构”后应为 consumed=3、remaining=5426、fixed=jian，后续可选“建”。

原生回归覆盖该精确序列、整词“构建”、`ni'hao` 部分选字、混合过滤及普通 26 键
分隔符。主机原生测试和 960×266、936×280 的现有真实 LVGL 拼音流程通过。
原始失败与修复后日志在忽略目录 `.work/s6-final-acceptance/pinyin-report-*`，
完整双架构包在 `.work/t9-fixed-consumption/packages/`；实机补验单独记录。

## 官方键盘快捷入口（默认关闭）

“设置 → 键盘与输入 → 快捷切换官方键盘”使用独立布尔键
`quick_official_keyboard`，缺失或非法类型按关闭处理。DB worker 按请求 ID 与键名确认
保存；失败保留原值并允许重试，等待中不重复提交。它与“默认使用官方键盘”独立。
关闭时长按地球选择有道输入法；开启时地球菜单仅保留三种内置布局。宽横屏恢复
0.2.23 的“取消 / 官方 / 单行或多行 / 完成 / 剪贴板”位置关系，官方宽度为 64dp；
竖屏使用键盘上方的功能区，短横屏使用顶部功能区的键盘图标。键帽和触摸网格保留。

主机真实 LVGL 覆盖宽横屏、短横屏、竖屏和 150% 界面缩放，检查入口互斥、位置、
关闭默认值、失败重试、连续点按、重启恢复、无效存储值，以及系统键盘返回保留草稿。
几何测试包含左右互换与短横屏展开。原默认官方键盘、交接、地球菜单和设置定向回归
通过，截图留在忽略目录 `.work/official-shortcut/`。AArch64、ARMv7/C++14 构建和
完整开发包架构检查通过；Y01、Y02、Y07、S6 已安装并恢复原数据，宿主与 boot ID
未变化。本批实机仅做安装与启动核验，新开关的日常实机体验仍由用户验收。

## 横屏键盘时序（资源常驻改造）

宽横屏、短横屏及展开键盘入场/退场为120ms（原180ms），竖屏保持180ms。
动画中重建按剩余位移计算时长；快照接口接受独立时长，历史/菜单默认值不变。
内置键盘首帧不等待扫描交接或OCR注册；硬件操作仍经异步释放确认及原字段身份检查。
诊断仅增加有界的请求、动画开始/完成、首帧和交接就绪时间，不记录输入文本。

主机普通场景六次采样中位数约3.7–4.0ms（包含诊断往返，非物理屏幕延迟）。
人为延迟硬件准备500ms时，旧版观察到约473–503ms才出现按键，新版约10–11ms；
此结果仅证明去除了前置等待，不作为实机帧率或所有场景的速度提升声明。
