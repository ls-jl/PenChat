# PenChat 0.2.1 独立拼音验收

## 实现

- 固定 libpinyinime 提交 `cda375cfa4aafa1791f42a628d4888eba0a3db36`，源码静态构建。
  基础词典随包只读，用户增量在应用私有 `ime/user.json` 中，不使用或复制系统词库。
- 原生单线程工作队列负责查询和学习，35ms合并查询，编辑会话/序号/候选版本防止过期回写。
  常用布局通过现有数据库工作队列保存，按键不等待写入；不改变数据库结构。
- 三种主布局、快速轮换/普通切换、长按选择、两份暂存组合、原码回车、官方确认/取消均有主机覆盖。
- 完成编辑才提交词频与新词；取消、密钥、OCR和粘贴不学习。清除和暂停学习入口独立于布局偏好。
- 旧共享解码适配、导出、模块加载及消息处理已删除，生产ELF检查不含原借用符号及协议。
