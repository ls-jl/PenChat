## 行为

- 短横屏（当前S6）只有在最新消息页、实际到达消息区底部时显示聊天胶囊。
  沿用现有10px底部容差；不以“正在跟随输出”代替实际位置。
- 阅读历史时隐藏，反向滑动不会提前弹出。点击回到底部或手动滑到底部后显示。
- 空会话及短对话本来已在底部，正常显示。上拉新建期间暂时隐藏，取消后按
  实际底部位置恢复；新空会话正常显示。
- 程序重建、字号/草稿高度变化和键盘开关统一使用同一个显隐判断，避免其中
  某条布局路径把历史阅读时的胶囊重新放回屏幕。
- 竖屏常显、长横屏现有方向切换规则不变；按逻辑宽高的公共布局分类处理，
  不硬编码S6型号或分辨率。保留现有160ms过渡动画。

## 2026-11-17：长草稿与三行上限（0.3.3 dev）

本节覆盖前文旧的横屏高度上限，阅读滚动仍沿用当前的自动／手动／关闭快捷模式。
横屏聊天底部输入区按最终字体行高、实际文字宽度和内部 dp 留白增长，最多显示三行
完整文本；超过后仅文字区滚动。短横屏也保留真实换行，不再把段落压成一行预览。
局部文字拖动包括其滚动边缘均由输入区处理，不转成聊天上拉新建。

聊天输入完成的显示资格使用独立的聊天字段标记，不再误用仅代表竖屏原位编辑的标记。
宽横屏／短横屏完成长输入后都能保持输入区可见。布局造成的滚动不计入快捷收起距离；
已有阅读锚点和底部跟随保持，用户主动阅读滚动仍可按原模式收起输入区。

延迟到布局保护结束后的滚动同样不能取消已有底部跟随；真实阅读手势才会解除。
关闭快捷模式时完成输入不写入显式唤出标记，防止输入区被永久固定显示。

键盘中的文字编辑区沿用原尺寸、位置、内边距和控件布局；三行要求只作用于聊天底部。
新用例覆盖三类横屏、75/100/125/150% 缩放、显式四行、长段落、8192 字符、局部滚动，
以及历史阅读位置完成输入后保持锚点和显式唤出状态。见 `bash scripts/test-input-stability.sh`。
