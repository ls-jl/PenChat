# 按键采样拦截与释放（0.2.22）

此前的只读旁听会让系统同时收到Home、扫描键事件，导致离开向导、重新进入系统扫描等，采集被中断或丢失松开事件。0.2.22使用仅限明确点击采样后的临时EVIOCGRAB，不修改按键映射，不向系统注入事件。

## 边界

- 动态发现候选输入节点，不固定event编号、设备型号或按键码。排除触屏、具有绝对/相对轴的指针设备、无按键设备和完整键盘。
- 所有候选均取得独占后才报告就绪；任一节点不可读、已有其他独占或按键未松开时，释放已经取得的资源并提示失败。
- 截止时间固定30秒。poll只接受正的有界超时，取消检查间隔不超过50ms，防止临界负数被解释成无限等待。内核evdev/RCU退出本身可能有短暂关闭延迟。
- 完整按下/松开后短暂排空重复报告，再释放全部独占和FD，最后发布完成结果；没有采到内容或缺少松开时，到期报超时，不继续占用。
- 不再保留旧Home跨后台采样例外。取消、跳过、取消勾选、返回、后台、桥接断开及进程退出均结束采集。取消先发原子停止信号，不排在报告磁盘I/O之后。
- 就绪前仅清理未保护的旧事件；取得独占后的快速有效事件保留，避免准备期间漏采。
- 不记录触摸轨迹或键入文本，不发送真实反馈测试。现有反馈和用户数据保留。

## 验证

- `penchat-feedback-key-tests`使用私有uinput设备，验证其他消费者收不到采样事件、完整采样提前释放、无输入/长按超时、取消、部分独占回滚、按键未松开拒绝、不可读节点回滚、指针/键盘排除及采集进程被杀后内核释放。两台授权设备运行通过。
- 主机缺少新建uinput节点的读取权限时，该内核测试明确返回77并跳过；不改工作站输入权限。短超时与路径注入只存在于测试目标，生产AMR检查确认没有该覆盖入口。
- 15项反馈服务测试及两种尺寸的LVGL页面/超时提示检查；针对性ASAN/UBSan使用现有MicroTeX静态注册抑制，未扩大抑制范围。
- ORANGE与113使用全目录隔离测试：真实候选Home/扫描节点在采样期间探测为busy，采样后恢复free；通过私有uinput源产生按下/松开验证向导完整链路。释放后向真实Home节点发送测试事件，截图确认系统Home正常，返回后数据仍可核对。自动注入与用户手按应区分。
- 两台设备均真实等待30秒验证超时弹窗、独占释放、触摸仍可操作以及停止采集。超时结果包含约0.4～0.6秒内核关闭耗时，不是额外的采样窗口。
- AArch64生产构建、AMR资源/许可/版本/strip检查及运行时无shell策略通过。唯一新增fork在未发布的退出清理单元测试中，不增加生产进程启动点。
- 测试后恢复私有/公共目录；宿主PID保持不变。截图、采集报告、构建私有配置与测试二进制不入Git。
