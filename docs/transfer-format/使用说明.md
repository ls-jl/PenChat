# PenChat 导入导出格式规范

格式版本：1。它独立于应用版本；外层规范 ZIP 只是资料包，不是聊天备份。

## 如何使用示例

1. 在电脑或文件管理器解压导出的格式规范 ZIP。
2. 把“示例聊天.penchat.zip”放到 PenChat/导入/聊天，不要再解压这个聊天包。
3. 把“示例预设.penchat-presets.json”放到 PenChat/导入/预设。
4. 如需导入普通 Markdown，将“示例参考.md”和“图片”文件夹一起复制到 PenChat/导入/聊天。
5. 在应用的“导入与导出”中刷新、预览并确认。导入原件保留。

示例只有虚构内容，不含账号、密钥或真实图片。示例预设是普通预设，沿用会话的模型与强度，不替换默认预设。导入示例不会自动调用 AI。

## 三种文件

| 用途 | 文件名后缀 | 导入位置 |
|---|---|---|
| 完整聊天与图片 | .penchat.zip | 导入/聊天 |
| 会话预设 | .penchat-presets.json | 导入/预设 |
| 普通参考文档 | .md | 导入/聊天 |

规范完整文件为“聊天格式.md”“预设格式.md”“Markdown导入.md”，与应用内查看的正文相同。

## 制作文件时

所有 JSON 和 Markdown 使用 UTF-8。模型由描述匹配，不使用另一台设备的内部模型 ID。不确定的可选字段应省略；不要把未知值填成零、false 或随机编号。

聊天包中的 CRC32 用于检查损坏，不是签名或可信来源证明。规范包、聊天包和预设都不应包含密钥、认证头、数据库、日志或不公开的思考续传内容。

导入会创建新的会话/预设，不覆盖原聊天。同来源同校验值默认跳过，可主动选择另存副本。默认预设替换需在预览中单独确认。

## 导出目录

格式规范保存在 PenChat/导出/格式规范。“持久化导出目录”默认关闭，正常退出应用会清理规范包及其他导出文件；请先开启此设置或复制需要保留的文件。
