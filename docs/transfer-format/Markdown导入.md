# 普通 Markdown 导入

把UTF-8的 .md 文件放入PenChat/导入/聊天，刷新后预览、确认。导入以文件名作为标题，全文保存为一条助手角色的“导入的参考内容”，不会猜测问答角色，不自动请求AI。

## 文字与图片

```markdown
# 示例参考

这是一份虚构的参考笔记，公式为 $a^2+b^2=c^2$。

![示例图片](图片/示例.png)
```

复制“示例参考.md”时，将“图片”文件夹一起复制到导入/聊天。当前文件列表只列出导入目录顶层的可用文件，不递归浏览子目录中的Markdown。

相对图片以该Markdown所在的导入目录为基准，只读取其子目录内的文件。常规行内图片语法如上；不可使用绝对路径、反斜杠、点号/父级路径段、符号链接或越界路径。当前实现不是通用HTML/资源抓取器，不把任意HTML图片标签作为本地附件导入。

http://与https://图片保留为链接，导入阶段不联网下载。缺图会在预览中列出，可取消或明确选择只导入可用内容；本地图片复制为应用资产，源文件不删除。

## 格式与大小

文件必须非空且最多32MiB；单个相对图片文件最多512MiB，准备文件时还会检查剩余空间。Markdown正文按原文保存，支持的显示能力与普通AI回复一致，包括列表、代码、表格和LaTeX公式。

## 重复与后续使用

相同来源和内容默认跳过，可选择另存副本。导入后保留现有会话、草稿和全局默认模型；需要继续聊天时由用户主动选择会话、模型和发送。再次导出聊天时，本地图片可以随聊天包一起备份。

## 不要混淆三个ZIP

格式规范ZIP需要先解压。示例中的 .penchat.zip 是可直接导入的聊天包，不要再解压它；普通Markdown则连同相对图片一起放入导入目录。
