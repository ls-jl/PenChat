# 会话预设格式 · 版本1

文件后缀为 .penchat-presets.json，内容为UTF-8 JSON对象。无需ZIP、图片或数据库，放入PenChat/导入/预设后刷新。

## 外层对象

| 字段 | 类型 | 要求 |
|---|---|---|
| format | string | 必填，固定penchat |
| version | integer | 必填，固定1 |
| kind | string | 必填，固定presets |
| app_version | string | 可选，来源应用版本 |
| items | array | 必填，1～2000个预设 |

## 每个预设

| 字段 | 类型 | 含义与默认值 |
|---|---|---|
| id | string | 来源ID；default专指默认预设，普通预设用其他唯一名称 |
| name | string | 必填，非空，最多64个字符 |
| prompt_mode | string | inherit沿用、custom自定义、clear清空；省略为inherit |
| prompt | string | 自定义提示词，最多32768字节；省略为空 |
| model | object | 模型描述；空对象表示沿用会话模型 |
| model_when | string | empty仅空白会话、always每次切换；省略为empty |
| effort | string | 强度；空字符串表示沿用会话，省略同样沿用 |
| effort_when | string | empty或always；省略为empty |
| compression_model | object | 指定压缩模型；空对象或省略则跟随聊天模型 |
| origin | object | 必填，source和checksum均为字符串 |

当前版本预设导入器接受的effort为：空字符串、none、api_default、low、medium、high、xhigh、max。none是即时；api_default明确不发送强度参数；空字符串不修改会话选择。不要将三者混用。当前文件导入验证不接受minimal；不要仅根据模型列表的可选档位猜测文件枚举。

非空model与compression_model描述需有endpoint、api、name字符串，可带provider。api使用responses、chat或anthropic；地址与模型名称用于本地唯一精确匹配，不能使用本地内部ID，也不附带凭据。

用户手动切换预设时先应用模型，再检查强度兼容性，各字段遵守应用时机。不支持的强度不会自动换成其他档；压缩模型未指定则恢复跟随聊天模型。

## 普通预设示例

```json
{"format":"penchat","version":1,"kind":"presets","items":[{"id":"example-preset","name":"示例预设","prompt_mode":"inherit","prompt":"","model":{},"model_when":"empty","effort":"","effort_when":"empty","compression_model":{},"origin":{"source":"example-preset","checksum":"example-v1"}}]}
```

source标识来源预设，checksum标识该版内容。标准导出使用去掉origin后的紧凑JSON的CRC32，生成8位小写十六进制。它是重复识别标记，不是可信签名；修改后应更新。资料包内还提供经实际导入验证的完整示例。

## 默认预设与模型匹配

id为default时，预览会准备替换默认预设并展示差异，必须另外确认。也可改为普通副本或跳过。资料包示例使用普通ID，不替换默认预设。

普通同名预设新增副本；相同来源与校验值默认跳过，允许另存副本。编辑/导入预设不会追溯修改已应用的会话，也不会自动打开预设入口或请求AI。

模型无法唯一匹配时显示待配置，允许预览中指定本地模型，不自动建立Provider。密钥、认证头、模型能力模板、内部ID和加密续传内容不进入文件。

## 限制

JSON文本最多32MiB、嵌套最多64层、解析事件最多100万次。UTF-8必须有效，字段类型必须匹配。不要用null代替有规定字符串或对象类型的默认值。
