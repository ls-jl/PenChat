# PenChat 0.1.13 · UI 布局检查

目标是让 960×266 的横屏界面清楚、易点、容易理解，不改变聊天习惯，也不靠缩小触摸区域塞入更多内容。
保留 ChatGPT 深色配色和现有主导航、输入胶囊、回底与上拉手势。

## 逐页结论

| 页面 | 截图发现与处理 |
| --- | --- |
| 聊天 | 检查空白、长草稿、消息图片、思考展开、表格和代码；保留阅读布局与胶囊位置。浮层增加半透明遮罩，避免与正文混淆。 |
| 历史抽屉 | 检查长标题、选择状态和长按菜单；保留三分之二宽度、底部新建/设置与点击遮罩关闭行为。 |
| 设置 | 七个常用入口用双列、44px 行高和 8px 间距排布；会话预设进入首屏，存储/版本信息下移。 |
| Provider 列表 | 添加与编辑按钮至少 44px；空列表说明下一步操作。 |
| Provider 表单 | 名称/地址/密钥/模型改成标签和值两层；保存固定右上角并突出；移除重复的底部保存/取消，返回箭头仍可放弃编辑。错误校验改为直接可见的弹窗。 |
| 模型配置 | 保存操作统一；六档能力与公开总结可完整显示在首屏，参数映射列表按统一宽度排布。 |
| API Key OCR | 检查提示、核对说明、重扫/取消；保持操作与系统 OCR 逻辑。 |
| 归档 | 空状态说明如何归档；删除使用危险色，与还原区分。 |
| 预设管理 | 新增固定在右上角；预设名称与配置摘要分层，每屏可完整浏览两条预设。 |
| 预设编辑 | 字段使用统一双列；每个应用时机改成并排的两段选择；提示词编辑入口独立一行，删除与保存区分。 |
| 相机 | 检查横屏与三个旋转方向的真实预览、快门和方向控制；保留既有布局。 |
| 裁剪 | 检查四向、缩放/平移；确认突出，系统相册复选框使用深色样式。 |
| 相册 | 文件名与缩略图居中对齐；空状态解释相册保存选项，分页按钮至少 44px。 |
| 笔头扫描 | 检查采集中、完整、部分和空结果；等待/无图像状态弱化且不可用，可用结果突出确认。采集与拼接算法未变。 |
| 选择浮层与弹窗 | 统一圆角、遮罩和关闭区域；检查模型、标题模型、强度、预设、思考选项和删除提示。 |
| 启动器与输入法 | 真实设备截屏；启动器重试使用独立深色文字样式，避免 Falcon 样式优先级造成白底白字。系统输入法保留原生界面。 |

## 截图与复现

交付工作区 `.work/ui-audit/index.html` 提供 53 个状态的截图对照，可筛选页面并点击原图。
包含所有 12 个原生页面，以及历史抽屉、菜单、弹窗、旋转状态、启动器和系统输入法。
部分补充状态没有旧截图，报告明确标注；不将其冒充前后对照。
截图以测试数据生成，启动错误页来自主动结束测试原生进程后验证重试；不是用户使用中的崩溃。

- `npm test`：实际 LVGL 进程回归及常用页面截图。
- `python3 tests/capture_ui.py --output .work/ui-audit/after/extra`：补拍表单、选项、OCR、非空相册及空状态。
- `python3 tests/device/presets.py`、`python3 tests/device/photo_orientation.py`：ORANGE 真实触摸、预设与四向拍照/裁剪。
- `python3 tests/device/ui_states.py`：在临时数据库中检查宿主输入法、启动失败页与重试，结束后逐字节恢复数据库。
- `python3 scripts/ui-gallery.py`：从已有截图生成本地对照页和 manifest；运行前需完成上述截图流程。

截图、测试数据库、构建产物不进入 Git；复现脚本和检查结论保留在源码中。
