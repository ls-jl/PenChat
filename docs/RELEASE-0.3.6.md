# PenChat 0.3.6 候选验收

候选应用源码为 `ad0c52c`，`package.json` 与 `package-lock.json` 同步为 0.3.6。之后的提交修改测试夹具和证据记录。两套完整安装包保存在忽略目录 `.work/release-0.3.6/packages/candidate1/`，以目录中的 `identity.json` 和 `SHA256SUMS` 为准。

本轮覆盖 0.3.5 以来的公式扩展、独立 CVI 更新渠道、推理强度滑块过渡、CVI 基础兼容、扫描预览操作、版本回退和增量备份还原。发布候选以本地验收为目的。

## 主机和安装包

- 主机构建和 209 条回归命令通过，包含 npm 回归清单与独立用例。原始失败和补验分开保留。修正了 27 项设置清单、竖屏停靠键盘菜单边界和输入框纯绘制层的旧断言。扫描诊断追踪使用独立启用的测试 worker，生产 worker 保持关闭。
- CTest 原生 63 项中 62 项通过，硬件反馈按键 1 项在主机按设计跳过，Y01 实机补验通过。完整 ASan／UBSan／LSan 的 scanner 15 项、原生 CTest 和真实进程补充用例通过。另有还原后端 19 项和真实还原页面 12 组带 sanitizer 的检查通过。
- 用已有独立 0.3.5 基线 `bc45836` 比较稳定渲染夹具。18 种布局、主题及倍率组合中 232 张截图逐像素一致，几何与词选择一致。新公式用单独的渲染用例和实机截图核对。
- `npm run check` 正常退出，工具仍提示可选 cnpm。AArch64 与 CVI ARMv7/GCC6/C++14 完整构建、AMR 身份、目标架构、资源、双 ABI 急救库约定、无 shell 和 Web 载荷检查通过。

## 隔离实机验收

- 四台均用对应候选安装和启动，验证 27 项设置入口、9 组增量还原用例、代表性 LaTeX、仪表／化学式与在线更新检查。
- Y01、Y07、S6 使用各自配置的 DeepSeek 和合成输入，覆盖对话、关闭思考与上下文压缩。Y02 使用本地假服务，覆盖断流与压缩等场景。Y01 首次测试把返回的正确答案 `1,073` 判错，修正测试断言后重跑三轮通过。测试后的三份临时配置已删除，23 个隔离 SQLite 证据副本已脱敏，验收目录复查无凭据匹配。
- Y07 官方输入法在补建测试 TLS 程序后通过，Y01/Y02/Y07 的扫描采集及丢弃循环通过。Y02 用真实采集结果通过原图打开、重开、点击底部「使用图片」和保存草稿图片哈希检查，未发送消息。
- Y07 隔离设备上进入回退页面，分别走「备份并安装」和不备份的二次确认路径，两次均实际安装公开已有的 0.3.5 并核对运行哈希。带备份路径核对清单中数据库文件哈希。两次均装回 0.3.6 后恢复原私有和公共树。Y01 和 S6 的普通更新安装桥接使用独立随机 AppID 核对实际安装和票据。
- 已结束的设备作用域均核对原私有数据、资产、设置、输入法记录及公共传输树恢复，宿主 PID 和 boot ID 一致。恢复后运行程序与候选包哈希一致。

S6 已通过资源常驻、独立更新源、安装桥接，以及隔离合成原图的解码失败重试、长图打开和缩放检查。自动笔头测试收到了 50 帧，过滤后没有可用扫描结果，因此无法覆盖真实纸面扫描后点击「使用图片」的链路。原数据恢复和宿主身份已核对。RK 和 CVI 候选的 scanner 二进制均与已上线 0.3.5 逐字节相同。这次采集证据不足以判定新版本发生扫描回归。此项保留待实际划扫验收，不将原图解码或其它机型的确认通过记为 S6 纸面测试通过。

综合收据在 `.work/release-0.3.6/acceptance-summary.json`。四台日志、首次失败、复验、截图和包审计位于同一忽略目录。本地保留候选，等未闭合的验收完成后再标记最终包。
