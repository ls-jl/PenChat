# 首次使用引导（0.2.24）

七页全屏原生引导：直接扫描成图片、键盘OCR、API配置、预设、聊天管理、模型与强度、上下文与数据管理。新旧用户均展示一次；前三页无跳过，第四页开始可结束，无强制观看计时，也不要求实操。

## 交互与视觉

沿用`theme.hpp`和共享图标，左右各约半屏，左侧原生控件时间轴，右侧24px标题、18px说明和44px操作区。每页4个阶段、每阶段1.6秒；原位移动演示触点，阶段对象只在当前页保留，最高每34ms更新一次。暂停、后台及销毁不持续重绘；不加入视频、GIF或新运行库。

演示使用独立场景，没有扫描、相机、网络和仓储对象。虚构密钥显示为星号，界面标注“操作演示”。第三页“去配置”才进入真实Provider页，现有键盘与OCR照常工作；退出Provider列表返回第三页。

完成后从“设置 → 关于 PenChat → 使用引导”重看，可随时关闭并回到关于所在的设置位置。现有主题没有替换；此次仅扩展引导界面，不重定义其他页面组件。

## 状态与保存

设置键`onboarding`保存`version:1`、`step:0..6`、`complete`，引导版本独立于应用版本，不改业务表结构。缺少完成标记时展示，异常步骤收敛到有效范围；完成后补丁更新不重复展示。关闭应用、Home和后台不等于完成。

首次路径的前进/返回/结束通过唯一请求编号交给DB工作线程保存，成功回执后才导航；失败留在原页并提示重试。队列有界，保存中的重复操作不生效。重看仅使用进程内进度，不清除完成记录。演示不创建聊天、不修改模型、预设、草稿和图片。

启动在现有会话与更新恢复快照读取后切入引导；结束恢复原页面。引导期间不发起自动命名或弹出更新提示；不注册OCR、不使笔头扫描具备采集资格。真实配置页的主动操作例外。
