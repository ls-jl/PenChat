# PenChat 0.3.4 降级目录交付

本次按用户指定版本 0.3.4 构建并验收，发布范围仅为服务器 `app/downgrade`。
不修改普通在线更新源，不创建 GitHub Release，不推送代码；后续继续在 dev 开发。

## 范围

包含 0.3.3 最终交付候选之后在 dev 累积的修复：横屏聊天输入框按真实字体度量最多
三行、长输入布局变化保留阅读跟随状态、单行／多行 OCR 偏好持久化，以及浅色横屏
编辑区域的颜色修正。编辑区域既有结构和高度规则保持。

熄屏、控制中心与真实退出分别门控；保留健康扫描模型与页面，关闭期间不触发采集、
触摸和后置相机。退出留证、挂载身份及暂时显示失败恢复沿用当前实现。真实物理熄屏
验收与软件故障注入分开，不把注入电源键当作真实熄屏证明。

启动失败页新增独立“降级”入口、双 ABI 轻量降级库、自动精简诊断、完整私有／公共
数据备份、包完整性与真实平台校验。历史目录已有 0.3.2／0.3.3，保留候选身份和已知限制。
RK 显示兼容按实际 DRM 能力选择下层或上层路径，适用于所有 RK DRM 设备，
没有 X6 型号／分辨率白名单；S6 继续共享合成。

## 构建与验收记录

版本在 `1761cb6` 一次更新，package-lock 根元数据同步。生产源基线为该提交；
后续发布检查修正仅涉及测试夹具与生成文件忽略规则，未更改生产运行时。

原始构建、完整主机命令矩阵、sanitizer、包检查、设备隔离恢复、截图和服务器核对记录
保存在忽略目录 `.work/release-0.3.4/`。最终结果以其中 `acceptance-summary.json`
和 `catalog/publication.json` 为准；未完成这些门槛前不发布版本元数据。

完整检查发现的旧测试假设分别修正并保留原失败：

- `DisplayPendingTest` 区分可安全位于系统 UI 下方的 surface 与需要前台许可的上层
  surface；`RefreshRateTest` 在媒体交接前先授予上层显示前台许可。仍断言未授权不呈现。
- 竖屏光标／选区释放可保留共享编辑菜单，首个外侧触点只负责关闭菜单。先断言不会
  点击穿透，再用新的阅读手势验证滚动，继续覆盖原键盘与草稿保持。
- 生产构建生成的 `assets/rescue/payload.json` 纳入忽略规则，不把生成描述文件加入源码。
- 旧渲染优化基线早于三行输入框改造，首例只在 `composer_text_bounds` 不同，九张图的
  像素完全相同。改用 `git archive e34c859` 的独立主机构建；该提交的 native/src/scripts
  tree 与版本提交 `1761cb6` 相同。18 组布局／主题／倍率的全部截图、几何和选字结果一致。
- Y07 两次 180ms 入场测到 172／173ms，追踪确认 `build_count=2`。现分别验收单次
  构建的完整时长和重建后的剩余位移时长，仍核对配置、首帧／结束顺序并记录实际耗时，
  不把重建路径的实测值伪写成 180ms，也没有修改生产动画。
- DPI 用例通过当前字段“取消”结束编辑，不再打开官方键盘后直接终止原生进程。
  全屏官方键盘的返回／确认交由独立用例观察。SDK 截图可能保留旧帧或透明 hole；
  全屏只读主层观察显式匹配本次测试的 PID 和编辑会话，拒绝过期身份与系统面板。
  原位官方编辑仍使用原有的页面／前台检查。五个观察器检查及全部 28 个发布工具单测通过。
- 刷新率旧用例的裸触点在 S6 一次短触摸租约取消期间未被接收。测试入口接入已有的
  有界触点确认：只有证明无界面变化、无活跃内核接触、前台恢复且是该次短租约取消时，
  才允许一次重试；不改变原生触摸许可、超时或系统面板规则。S6 最终刷新率复测的
  30／60Hz 三类底部检查均通过，没有使用触点重试。
- S6 合成长原图已成功解码，旧两进程双击缩放未完成。改用已有 helper 的单进程
  `--double` 完整短触点序列，避免两次 150ms 点击加启动开销跨过既有 350ms 窗口；
  应用阈值未修改，首次失败重试、三次重开与 2x 缩放复测通过。

Y01 本轮离线，不计作当前版本实机通过。Y02、Y07、S6 的专项使用隔离数据、本地假
服务和假凭据；每个作用域恢复数据库、设置、私有资产、IME 和公共传输目录，核对
MiniApp 宿主 PID、boot ID 与恢复后的真实原生 ELF。不会重启系统宿主。
自动传感器帧及合成原图流程不等于新增纸面光学质量验收，未知 RK 机型也未获得实机
扫描适配结论。

主机完整命令矩阵共 190 组，原失败和对应补验分别保存。扫描器 sanitizer 15 个目标、
原生 sanitizer 58 个目标及后续扫描／编辑器检查通过；其中硬件按键项按预期跳过，
不计作主机硬件通过。`npm run check` 仅报告既有的可选 cnpm 提示。

在线设备验收汇总覆盖 Y02 13 个、Y07 14 个、S6 13 个作用域，包含明确的失败补验映射；
最终以机器可读汇总中的有效结果为准。截图是设备／渲染证据，不代表新增人工纸面、
物理熄屏或未知机型的验收。
