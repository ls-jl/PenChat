# 短横屏文字与表单布局

S6 使用 Falcon 配置解释后的逻辑尺寸，归入 `CompactLandscape`。此分类不与硬件型号或固定分辨率绑定。

## 本次修复

- 设置以独立的四组连续布局排布；键盘设置、预设、连接配置、导入导出、反馈与更新表单复用单列测量排布。文字使用原字号；行内开关及箭头保留独立空间，长内容仍可按原规则省略。标题和说明不再挤在长横屏的半宽列中。
- 短横屏双行字段根据实际字体行高计算标签及控件高度。字段通过纵向滚动保持可达，不截去字形下沿。
- 归档标题占独立一行，下方保留查看、还原、删除三个操作。
- 枚举选项（思考显示、历史时间、编辑策略、联网默认、快捷唤出、接口/厂商/默认强度及预设字段）在三类布局统一使用 `choiceMenu` 内容大小悬浮菜单，保留原保存语义。菜单就近展开，当前项高亮；点击外侧关闭且不触发底层操作，多选项只在菜单内滚动，不增加全屏标题和关闭栏。字体设置的说明按实际高度为下方滑杆留位。
- 公共选中控件先完成布局再测量文字宽度，修复新建控件宽度尚未解析时被压成24px的问题。单列重排保留选中图标的左侧空间。

长横屏原双列表单和竖屏原位键盘行为保留；相册、消息阅读、网格与富文本内部版式不由表单排布接管。超长用户标题、模型名称等仍使用现有省略及完整查看入口，并非强制所有内容常驻展开。

## 定向检查

`python3 tests/test_compact_page_text.py` 使用真实主机LVGL进程，覆盖两种短横屏尺寸、名称/说明/开关边界、设置返回位置、预设、归档和长选项，以及长横屏/竖屏布局保留。只写虚构测试配置，不请求模型或操作设备。

主机截图另核对 Provider/模型、兼容设置、导入导出、格式规范及反馈页面。开发包构建与安装不等于真实手势验收；本轮未执行整套发布回归或升版。

`python3 tests/test_choice_menus.py` 覆盖三类布局的小菜单边界、当前项、外侧关闭、选项应用、局部滚动、设置阅读位置及未保存表单隔离。

## 设置首页四组

所有23项保留在一个纵向滚动页，顺序为模型、工具调用、聊天、应用。设置页按逻辑布局类别直接计算行列，不再经过通用表单重排，也不再给每项写死纵坐标。

| 分组 | 依次包含 |
|---|---|
| 模型 | 模型管理 |
| 工具调用 | 新聊天联网搜索 |
| 聊天 | 会话预设、思考过程、自动命名、命名模型、自动上下文压缩、自动压缩阈值、图片自动发送、历史时间显示、编辑消息、重试前提示归档、归档会话、上滑新建灵敏度、横屏输入框快捷唤出 |
| 应用 | 字体大小、键盘与输入、导入与导出、持久化导出目录、连接保留时间、检查更新、问题反馈、关于 PenChat |

长横屏保留双列，模型管理、联网默认、输入框快捷唤出、反馈及关于横跨两列；其余按顺序两两配对。竖屏与短横屏单列。行高56px、行距8px、列距16px；组标题16px，上一组末行到下一标题间隔16px。标题随正文滚动，关闭选择菜单、切换开关及子页面返回保留原位置。设置键、默认值、数据库和模型管理内部层级不变。

`python3 tests/test_settings_groups.py` 定向验证三类布局的四组顺序、23项可达性、行列与间距、文字边界、菜单/子页返回、开关及重启恢复。测试和截图仅使用主机虚构配置，不调用模型。

## 聊天悬浮面板

- 横屏余额入口改到聊天左下，与历史按钮上下对称；竖屏入口不变。余额展示使用独立可滚动悬浮面板，只保留一个全账户刷新，不重建聊天页。
- 所有机型的加号菜单使用输入胶囊的实际逻辑矩形：左边精确对齐，下边至少低10px；高度不超过实际选项行数和内边距，内容过多时仅在面板内滚动。
- 在固定左边及下边约束内选择最靠近屏幕竖直中心的位置，宽度按文字与图标测量。取消竖屏五行限制；菜单可覆盖输入胶囊和键盘，使用高于键盘的独立层，保留正在输入的拼音。
- `tests/test_attachment_menu_layout.py` 和平台布局原生用例覆盖锚点、自然尺寸、屏幕边界、菜单滚动与保留编辑。`tests/test_balance_ui.py` 使用本地假余额验证三类布局与聊天状态保持。
