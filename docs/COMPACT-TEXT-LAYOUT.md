# 短横屏文字与表单布局

S6 使用 Falcon 配置解释后的逻辑尺寸，归入 `CompactLandscape`。此分类不与硬件型号或固定分辨率绑定。

## 本次修复

- 设置、键盘设置、预设、连接配置、导入导出、反馈与更新表单复用单列测量排布。文字使用原字号；行内开关及箭头保留独立空间，长内容仍可按原规则省略。标题和说明不再挤在长横屏的半宽列中。
- 短横屏双行字段根据实际字体行高计算标签及控件高度。字段通过纵向滚动保持可达，不截去字形下沿。
- 归档标题占独立一行，下方保留查看、还原、删除三个操作。
- 思考显示、历史时间和编辑消息默认策略在短横屏使用纵向选项，保留原保存语义。字体设置的说明按实际高度为下方滑杆留位。
- 公共选中控件先完成布局再测量文字宽度，修复新建控件宽度尚未解析时被压成24px的问题。单列重排保留选中图标的左侧空间。

长横屏原双列表单和竖屏原位键盘行为保留；相册、消息阅读、网格与富文本内部版式不由表单排布接管。超长用户标题、模型名称等仍使用现有省略及完整查看入口，并非强制所有内容常驻展开。
