# 共用业务、三类布局与平台后端

此文描述 `dev` 合入 S6 历史后的组件边界。AppID、0.2.34 版本和数据库结构保持原样；
本次为开发整合，没有发布或推送。S6 原分支保留。

## 几何与布局

平台先解释 Falcon 配置，`Screen::fromConfig` 输出逻辑尺寸。Rockchip 保留已有逻辑
尺寸；S6 的物理面板在90/270度时交换一次。触摸再按独立触摸旋转/偏移映射一次，
不能用布局分类选择硬件，也不能把 Y02 已有逻辑画布再次交换。

`layout.hpp` 的 `LayoutClass` 使用整数比较：

| 分类 | 条件 | 当前示例（不是运行时默认值） |
| --- | --- | --- |
| Portrait | 高 > 宽 | Y07 |
| WideLandscape | 宽 >= 高×3 | ORANGE、Y02 |
| CompactLandscape | 其他，含正方形 | S6 |

`AppLayout` 集中提供安全边距、聊天/弹窗区域、扫描工作区、相机工作区和引导分区。
`EditorLayout` 提供键盘、候选/功能区、浮层及反向命中几何。短横屏默认键盘使用实际逻辑几何，顶部单行、全宽按键；按需展开右侧大编辑区
时才保留原局部设计画布与整体变换。设计画布不是设备分辨率回退。单指与按
tracking ID处理的双触点按键统一读取当前布局，只有展开缩放模式才做一次逆变换。

- 竖屏：原控件内编辑、底部键盘、候选/功能共行、圆角安全区、输入栏三倍高度上限、
  下推收起、剪贴板覆盖键区、官方键盘保留上方原页面。
- 长横屏：左右编辑布局，聊天输入短文本单行、长文本最多两倍高度后局部滚动，
  阅读时隐藏/恢复胶囊。
- 短横屏：默认顶部单行与全宽键盘，按需展开原左右编辑分区；其他页面沿用测量、
  省略和滚动等自适应能力。

主题、图标、按钮、设置行、列表、选择器、弹窗、Markdown/公式、图片网格及查看器
仍只有一套实现，不新增三个业务页面副本。公共控件继续接收父区域和尺寸；结构差异
由布局几何提供。聊天、三个 API、数据库、模型、预设、压缩、消息操作、导入导出、
反馈与更新状态机不按设备复制。键盘状态、拼音/学习/纠错、选区、撤销和剪贴板共用；
地球长按为500ms。`chatDraftPreview` 只用于短横屏的单行预览，不修改草稿原文。

## 平台边界

| 公共接口/所有者 | Rockchip | S6 |
| --- | --- | --- |
| `DisplaySurface` / LVGL `Display` | DRM overlay | Falcon共享内存、Alpha合成 |
| `InputFocus::permissions` / NativeTouch | 只读系统覆盖层状态、顶部手势让行 | 输入租约与显示租约分离、系统窗口在上 |
| `Hardware` / `CaptureStream` / scanner任务 | V4L2/ISP与严格传感器profile | CVI VI/VPSS、固定光学区域、灯/按键配置 |
| `Inference` / Stream32输出契约 | RKNN | CVI runtime |
| OCR编辑会话 | 准备/激活、字段间保留、Y07笔头路由 | 旧版注册式接口、注销确认 |
| 相册/裁剪/浏览 | V4L2拍照和方向传感器 | 声明没有独立拍照设备 |

显示提交 `true` 表示接受，`false` 表示暂时忙；保留最新CPU帧稍后重试，不增加帧副本。
DRM 的 EBUSY/EAGAIN 不再抛致命异常，永久错误带明确原因。`topRegion` 能力保留
Y07 官方输入所需的上方局部显示；不支持的后端不启用此模式。S6 不链接旧 CVI VO
实现，不作未知固件回退；精确固件hash、槽位所有权、过期时间和退出恢复保持。

焦点状态统一计算输入、采集和底图显示许可。失去输入焦点不一律隐藏底图：共享合成
保留位于系统窗口下的画面，DRM让出平面。Y07额外的控制中心可见性检测仍参与输入
判定。失焦取消触点、键盘重复、拖动与越界滚动，不改变有效阅读位置。

OCR旧接口支持与新准备阶段并存；必要注销未确认前不开始新采集，旧编号不取消新
注册。字段切换可保留系统注册和键盘控件；不同字段仍有独立ID、撤销和密钥显隐。
系统编辑器仍是手动入口，没有恢复 Falcon 拼音借用。

扫描仍为单份像素所有权的RAM流水线和32/24/8窗口；模型、ABI、ION、灯、原始帧
传输和纸面ROI是后端责任。松笔截止使用真实evdev事件时间，保留各传感器原有开流
策略及统一连续漏1～8帧继续、漏9帧停止。CVI反复重开问题见
[独立待办](KNOWN-ISSUES.md#s6-cvi-001原图采集反复重开仍不稳定)。

## 构建和开发包

源码、业务资源共用；依赖前缀、构建目录、原生ELF、扫描模型和暂存包按架构隔离。

```sh
bash scripts/build-lvgl.sh rk3562
bash scripts/build-scanner.sh rk3562
python3 scripts/package-dev.py rk3562

bash scripts/build-lvgl.sh cv1826-s
bash scripts/build-scanner-cv1826-s.sh
python3 scripts/package-dev.py cv1826-s
```

`rk3562` 是 Rockchip/AArch64 构建目标，`cv1826-s` 是 S6/ARMv7 构建目标，设备选择仍由严格profile和真实配置决定。
`build/package-rk3562/` 与 `build/package-cv1826-s/` 分开输出相同应用身份的开发包。S6 不会
使用 Rockchip 更新源。`tests/check_amr.py` 可传入开发包路径，原默认发布包检查不变。
不将工具链、DSO、截图、词库记忆、用户数据或安装包提交Git。

## 构建命名

原生构建目标按芯片与构建变体命名：`rk3562`（AArch64）与 `cv1826-s`（ARMv7），不再用
ORANGE、S6 机型名标识构建。机型 profile、设备名单和历史适配记录中的名称保持原意。
开发包目录分别为 `build/package-rk3562/`、`build/package-cv1826-s/`，分发文件为
`<AppID>.<版本下划线>-rk3562.amr`、`<AppID>.<版本下划线>-cv1826-s.amr`。
库暂存分别为 `arm64-rk3562`、`arm32-cv1826-s`。旧构建缓存仍可留作本地历史产物，
不要直接移动含绝对路径的CMake缓存；新目标使用独立构建目录。

`cv1826-s` 表示当前 S6 使用的构建变体；芯片型号仍为 CV1826，硬件识别与设备 profile 不变。

## 长横屏左右互换与手动输入法

长横屏可在“设置 → 键盘与输入”开启“横屏键盘左右互换”，键区与编辑区整体交换，
不镜像按键顺序；竖屏与短横屏保持原布局。偏好在下次打开编辑器时应用。
三类布局都通过长按地球500ms后的“有道输入法”菜单项进入系统输入法；
短按只切换原有三种内置布局。详见 [键盘互换说明](WIDE-KEYBOARD-SWAP.md)。
