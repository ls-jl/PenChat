# PenChat 0.2.25 · Y07 适配与验收状态

同一 AppID、同一 AArch64 包。运行时屏幕只读 Falcon cfg.json，不以板型写入屏幕默认分辨率；
不迁移或覆盖业务数据，不改数据库、桥接版本、网络接口或 Stream32 算法。

## 实现

- 共享 `AppLayout`：竖屏没有86px侧栏留白，聊天全宽、底部胶囊，子页标题与动作随正文滚动。
  设置及各业务表单单列；模型匹配填充按钮与字段保持关联；相册按宽度分配列数。
- 历史抽屉仍为三分之二屏，长按操作单行横向滚动；归档条目显示标题及独立操作行。
  会话信息中的指标名称与数值作为同一个布局单元，不交错。
- 竖屏编辑器：全宽正文在上，依次为组合、候选、操作和固定键盘。
  三种主布局、数字/符号、独立拼音/学习、选区、剪贴板、放大镜和 OCR 保留。
  展开候选与剪贴板仅覆盖正文。官方编辑器正常过渡不因页面隐藏而被误取消，
  原生进程重建会关闭遗留的官方会话并拒绝迟到结果。
- 竖屏上拉使用 `min(阅读高度, 阅读宽度/2)` 的空间基准，当前 Y07 约226px；
  横屏、偏移、防误触及空聊天规则不变，触摸旋转/偏移只应用一次。
- 七页引导为上方动画、下方说明；键盘示意也采用上下排列。旧完成记录保持有效。
- 独立 Y07/SC2356 752×440采集配置；使用驱动 LED 类，不导出/抢占 GPIO。
  退出时恢复亮度、V4L2格式和系统采集服务。110MiB磁盘环对应348张原尺寸灰度帧；V4L2缓冲仍按完整NV12帧申请。
  常驻进程、32/24/8窗口、逐帧光照估计与原图输出保持原实现。
- Y07/GC08A8 使用960×720预览和3264×2448拍照；必要时暂停预览再采集高清。
  快门落在预览转换期间也等待高清帧，不保存预览冒充照片。高清缓冲用后释放，
  相机事件携带代次，过期照片清理而不进入新页面。裁剪和浏览仍用原图像素与双指手势。

## 内存与画面开销

Y07键盘、相机、扫描各20次循环通过；键盘循环前后文件句柄均为14个。
测试照片尺寸3264×2448，20次相机进出期间主进程 `VmHWM` 为162,132KiB
（约158.3MiB，包含当次聊天/图像/相机状态，不代表每个子进程总和）。
两个CPU整屏ARGB缓冲按实际逻辑尺寸共约5.24MiB；高清采集的4个NV12缓冲
约45.7MiB，仅拍照时持有。上述后两项是尺寸计算值，DRM实际对齐会增加少量空间。
未将黑场拍照或注入手势当作实际照明、帧率和肉眼交互体验通过。
