# 问题反馈与机型适配

设置 → 数据与应用 → 问题反馈。描述可留空，最多 2,000 字，请勿填写密钥等凭据。先预览报告及字节数，再点击发送。不会自动上传，也不会发送原有完整诊断文件、运行日志、聊天或图片。

## 报告与本地保存

报告由原生后台服务单独生成，包含白名单运行计数、错误类别及网络耗时，以及实际 Falcon 启动配置和应用采用的显示/触摸参数。设备信息来自 uname、设备树、只读输入设备能力查询和有界 V4L2 查询；不启动摄像头或笔头采集，不修改格式或控制参数。无法读取的字段标为未知或附带 errno。

自动诊断不包含正文、提示词、图像、凭据、认证头、完整 URL、加密思考、序列号、MAC、IP 或主机名。物理按键采集记录的是输入节点、设备名称、能力和相对时间，不记录触摸坐标或输入文字。

私有 `.feedback/` 保存当前及上一次运行的白名单诊断（各最多 500 条 / 256KiB），本次描述/向导草稿和待发队列。单报告最多 1MiB；超限时优先省略旧诊断并注明。待发报告最多 10 份、合计 10MiB，不自动淘汰失败报告。发送成功后删除正文，只保留最多 10 条编号和时间回执。删除是本地操作，不能删除服务器已收到的内容。

## 适配向导

“帮助开发者适配更多机型”每份反馈默认关闭。勾选不会监听，点击采集入口后按扫描按钮、Home、核对结果的顺序操作。每一步最长30秒，可重采、跳过或停止。就绪后按下并松开目标按钮，完成后立即释放拦截；超过30秒仍未完成则提示超时并恢复按键。

动态发现 evdev 节点，只读打开候选物理按键，并通过EVIOCGRAB临时阻止系统处理其实际功能，不注入事件。任一候选无法拦截时整体失败并释放已有拦截，不继续不受保护的采样。不固定 event 编号、扫描键或 Home 键码；排除触屏、鼠标、其他指针设备和全键盘，避免记录输入。保留扫描进程及模型的现有常驻策略，等待扫描硬件释放并注销 OCR 后才监听。

Home与扫描键仅在采样窗口内暂停实际功能；不再允许Home采样跨后台继续。事件及时落盘，返回后核对。取消、超时、完成、桥接断开和进程退出均释放独占并关闭监听。中途退出可看到已保存的按下事件，并如实显示缺少松开；不自动继续监听。信息只供开发者判断，不修改设备配置。

## 上传和重试

仅 HTTP 201 且 JSON `ok` 为布尔值 true 时确认成功。反馈使用独立连接分区，不复用 Provider 凭据。DNS、指定节点之间的连接目标覆盖使用 libcurl [CURLOPT_CONNECT_TO](https://curl.se/libcurl/c/CURLOPT_CONNECT_TO.html)，保留原 URL、Host、TLS SNI、代理和证书校验。

临时连接错误、429、5xx 和 507 最多在首次失败后后台重试 3 次，间隔 10 / 30 / 120 秒加少量抖动；429 遵守更长 Retry-After。网络/5xx/507 才轮换节点，成功路径下次优先。报告编号和内容不变，服务器可能已收到超时请求，不能保证服务端去重。非临时错误直接停止；可手动重试开启新一轮、停止自动重试或删除。重启保留剩余次数和到期时间。此规则不改变聊天请求的重试行为。

## 私有构建配置

公开源码不含上报凭据。未配置时仍可预览，发送按钮不可用。使用 Git 忽略文件 `.work/private/feedback.json`，或配置 `PENCHAT_FEEDBACK_CONFIG` 环境变量 / 同名 CMake FILEPATH：

```json
{"endpoint":"https://example.invalid/api/logs","token":"配置自己的令牌","nodes":[]}
```

只接受 HTTPS 和有效节点 IP，生成头文件在忽略的构建目录中。不要把配置、接入说明、真实令牌或报告加入 Git。令牌最终位于原生安装包中，可以被提取，不能把共享上报令牌当作不可提取的秘密。更改配置后重新运行 CMake 及原生构建。

## 测试

`tests/test_feedback.py` 使用主机独立原生探针与 loopback 模拟服务；`tests/test_feedback_ui.py` 检查两种屏幕尺寸及失败通知。主机环境变量 `PENCHAT_TEST_FEEDBACK_CONFIG` 仅存在于非 AArch64 测试构建，生产程序无运行时服务覆盖入口。`feedback.test` 也仅为显式开启测试配置的主机构建可用。

`python3 tests/device/display_config.py --serial <授权设备> --feedback` 隔离和恢复私有/公共目录，不发送报告，使用真实触屏事件以及测试辅助程序产生的物理按键事件对，检查采样期间扫描键/Home不触发系统功能、30秒超时，以及释放后Home恢复。真实手指按键体验仍应与测试注入区分。

0.2.22起使用有时限的独占采样，替代0.2.20/0.2.21的旁听策略。`penchat-feedback-key-tests`仅创建私有uinput节点，检查拦截、提前释放、超时、取消、占用回滚和进程异常退出释放；主机无设备读取权限时明确跳过，需在两台授权设备运行。测试目标的路径/短超时注入不进入生产程序。
