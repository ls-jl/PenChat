# DPI 与全局缩放

本实现最初在独立 `feat/dpi-global-scaling` worktree 完成，基线为 `86844f4`，
后续完善从 `ff99040` 继续。2026-11-14 将 `422ef60` 合并回 `dev`，保留合并前
`1b3c688` 所含的竖屏菜单、摘要页与扫描恢复改动；下文原分支验收记录仍保留。
设备的 density 保持 100%；界面倍率现可在“设置 → 应用 → 界面缩放”中调整，
范围 75%–150%、步长 1%，默认 100%。使用现有 app_settings 的 ui_scale_percent
整数键，无 schema 升级、物理 DPI 推断或根节点变换。下方早期验收记录保留其
当时“设备固定 100%”的测试条件，不代表当前产品限制。

## 单位契约

`UiMetrics` 是 C++14 纯计算层。`dp(n)` 在 64 位整数中合并 density 和 UI
百分比，最后一次四舍五入；负数对称取整，越界报错。`sp(n)`另将独立的字体百分比一起组合，最终只取整一次；`dp()`及`identity()`仍只表达几何。App 启动时读取保存值，后续只在 UI 线程的安全时机替换度量。

| 输入 | 处理方式 |
| --- | --- |
| 设计留白、控件尺寸、圆角、描边、空间触摸容差 | 调用方显式 `dp()`，或取对应指标集合 |
| helper 的 x/y/w/h、LVGL 测量结果、Falcon 逻辑坐标 | 已解析像素，直接传递 |
| `LV_SIZE_CONTENT`、`LV_PCT()`、圆形半径特殊值 | 保持 LVGL 编码 |
| `UiFont` 角色及原始设计字号 | 通过`sp()`组合density、UI和字体倍率，再交给原有FreeType字体缓存 |
| `font(int)`、`label(..., int)` | 最终像素字号，绝不隐式再次缩放 |
| 全应用字体75%–150% | 沿用`reading_font_percent`旧键，与UI/density合并后取整一次；覆盖所有文字角色 |
| 原图、相机传感器、裁剪保存像素、PNG tile、缓存字节预算 | 保持其自身单位 |
| 列数、索引、比例、动画时长、超时、token 和字符限制 | 无单位或业务单位，不缩放 |

语义字号保留同号不同角色：正文 21、按钮 20、页面标题 26、字段标题 15、
字段值 19、设置标题 20、说明 16。Composer、表单说明和其他原有字号也有
明确角色。菜单、输入与键盘同样使用独立字体倍率；阅读、Markdown标题/代码/表格使用最终正文大小及明确的内部间距。详见[全应用字体大小](FONT-SIZE.md)。

## 覆盖范围与保留边界

| 范围 | 当前处理 |
| --- | --- |
| 公共 box/button/field/pageHeader/pageAction/settingsRow | 内部度量、字号和重排使用同源指标；外部几何保持像素语义 |
| AppLayout、composer | 三类布局、增长、工具行、停靠、返回底部和安全留白统一解析 |
| 设置、Provider、模型与协议表单 | 内部尺寸、字号、间距、字段动作锚点及单列表单重排 |
| 历史、归档、会话、预设、压缩、回复选择 | 行、标题、动作、弹层和阅读区域 |
| 反馈、更新、导入导出、网页、余额 | 页面内部度量、按钮和可读文本 |
| 附件/模型/强度菜单、对话框、阅读选择 | 尺寸、留白、行高、图标、菜单安全定位 |
| Markdown、数学、表格、共享图标 | 最终字号和内部设计尺寸；100% 保留原渲染，齿轮蒙版复用 |
| 相机、裁剪、相册、扫描查看 | UI 控件与工作区布局；采集、图像转换和后端协议不变 |
| 引导 | UI 文本和控件统一解析；非 100% 长文本局部滚动、页脚按测量宽度换行 |
| 键盘、候选、剪贴板、选择/放大镜 | 使用适配后的 KeyboardDesign/EditorLayout 与有效倍率 |

LayoutClass 根据 Falcon 已解释的逻辑几何分类。ScreenSafety 的屏幕圆角
包络仍是逻辑屏幕约束，不随 UI 倍率重复放大。引导演示的 400×150 插图坐标、
640×360 渲染上限和主机图标样本格是独立素材/测试单位。

下拉创建仍按按下时冻结的未遮挡 reader 几何计算，不再乘 UI 倍率。
NativeTouch 的旋转和偏移仍只处理一次。双击/长按时间、500ms quiet guard、
160ms 回弹和图像缩放比不变；普通点击/拖动等设计空间容差由统一指标解析。

## 键盘的完整按键适配

键盘优先保证按键完整。从请求倍率向下按 1% 检查三个内部布局的键帽、文字
行高与边界，选择可容纳完整键盘的最大倍率；下限为 `min(请求倍率,100%)`。
UI100%沿用现有几何；独立字体非100%时仍检查实际文字行高。某布局文字放不进键帽时，仅逐像素收小该布局的Character/KeyFunction字体，候选、拼音和菜单保留所选最终字号。所有按键及触摸边界保持完整。选择专用编辑器不执行按键适配。

紧凑横屏既有 960×266 设计画布仍由 EditorLayout 显式适配到真实逻辑屏幕，
它不是屏幕分辨率 fallback。候选、控制、选择和触摸坐标使用同一适配结果；
字母、数字/符号、九键、候选展开、紧凑展开都保留原模式边界。

诊断 `editor.requested_scale/effective_scale` 区分请求和实际倍率。
缓存只保留当前解析结果，键包含宽高、选择模式、inline chat、分区交换、
紧凑展开、密钥模式、圆角能力、官方 IME 占用高度、density、界面倍率与字体倍率。
`layout_resolves/layout_cache_hits` 可检查复用情况，不做永久多版本几何缓存。

## 消除重复工作

键盘一次解析后复用；同一状态的 100 次诊断不增加 layout resolves。
竖屏表单先集中赋宽和样式，再统一测量，最后安排行位置；创建局部 row 索引，
去掉每行遍历全部设置控件与逐行强制 layout。`layout_work` 记录批次和行数。
通用按钮复用已经获得的键盘祖先判断；字体继续使用既有缓存。

主机五次独立进程比较（长 Markdown reader、编辑器、100 次诊断及 Provider
表单）结果保存在 `.work/dpi-final/bench-{before,after}.json`：p95 诊断耗时的
中位数 18.178 → 18.336ms，RSS 高水位中位数 52,584 → 52,488KiB。
此结果属于近似不变，不能据此宣称帧率、输入延迟或整体响应速度提升；可以
确认的是重复几何解析被消除，8 行表单共用一次宽度相关测量（另有初始同步）。

## 正式设置与运行时切换

设置页使用当前倍率；调整滑块或加减按钮只改变局部示例。恢复默认只把草稿
设为 100%，返回会取消未保存调整。保存经 DB worker 的请求 ID 确认成功后，
重建界面并返回设置列表的“界面缩放”行。存储失败保留当前倍率和预览值，
可重试。后台或系统面板打开期间只完成持久化，前台输入许可恢复后再生效。

启动读取 ui_scale_percent：缺失、非整数用 100%，整数夹紧至 75–150；主机
显式 --headless --ui-scale-percent 仅覆盖本次启动，不自动写入设置。设备仍
拒绝命令行实验参数。全应用字体单独保存于原reading_font_percent键，75%–150%、缺省100%；与界面倍率合并后取整一次。字体页也使用异步保存确认和安全生效时机，未保存预览不会改变菜单、页面或键盘的当前字号。

RichText::setMetrics 清理公式/布局缓存但不重启 FreeType 或进程级 MicroTeX；
键盘当前布局缓存失效，原 LVGL 控件及其图标随重建释放，旧图片请求按原有
身份检查丢弃。字体继续使用现有字形 LRU。保存相同倍率不触发缩放失效。
75% 下历史菜单、页面动作及边缘控制保留至少 44px 触摸尺寸，相邻留白和
紧凑键盘头部同步给最小目标留出空间；100% 原有几何不变。

离开聊天时保存消息 ID、阅读区域和文本位置；倍率变化后恢复同一内容，
图片或无文本区域用消息内相对位置。靠近末尾时以合法滚动范围夹紧，不能
制造空白来强行保持像素位置。原来跟随底部的仍跟随底部；生成、会话参数、
草稿及待发送图片不会因设置更新而被重置或自动发送。

定向验证入口：tests/test_ui_scale_settings.py、test_ui_scale_lifecycle.py、
test_ui_scale_attachment.py，以及真实 LVGL 度量/控件测试。设备验收使用
`tests/device/dpi_acceptance.py --serial <授权序列号> --package <完整 AMR> --scale-settings`，

本批基线、截图、构建日志和安装结果位于 `.work/ui-scale-settings`。

## 主题、排版与菜单统一入口

主题使用 `ThemePalette`，度量继续由 `UiMetrics` 唯一解析。设计值通过 dp；
字体排版的 em 以最终字号计算，实际 LVGL/Falcon/图片坐标不重复转换。
`minimumTouchTarget()` 表示历史动作和圆角边缘的 44 logical 触摸下限，
`touchTarget()` 将该下限与已解析设计值合并；不对全部控件透明扩大点击范围。

详见 [单位边界与审计清单](UI-UNITS.txt)、[主题](UI-THEME.md)、
[Markdown 排版](MARKDOWN-TYPOGRAPHY.md)、[空状态清单](UI-EMPTY-STATES.txt)
及 [菜单过渡与强度、余额](UI-MOTION.md)。

本轮以 `ac977ec` 为兼容基线，保留界面缩放 75%–150%、独立字体设置及完整

## 刷新率与通用底部缓冲

“应用 → 界面刷新率”支持30/60Hz；未配置时横屏30、竖屏60，显式选择持久化后优先。
刷新率更新显示、动画和输入调度，并同步S6提交节奏，不参与dp或触摸坐标换算。
所有布局共用10dp入底、24dp离底、120ms持续确认的视觉缓冲；尾部预留空间不再随
输入框显隐变化。业务上的实际底部判断和手势时间规则保持各自语义。
详见 [刷新率与底部控制](UI-REFRESH.md)。
