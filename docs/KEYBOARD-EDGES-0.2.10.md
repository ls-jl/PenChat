# PenChat 0.2.10：A / L 边缘触摸修复

## 原因与行为

26键第二行居中错位，A、L外侧各留下约30px。旧命中区域仅扩展4px，
外侧空白不会输入。实际进程回归在0.2.9复现：A行逻辑x=0点按后字符数仍为0。

另外，左边缘会先参与侧滑返回仲裁。轻微向右漂移超过原12px门槛后，
不足完整返回距离的操作不会返回，也不会输入，造成少数边缘按键掉字。

本次保留字母位置、按键外观和行高，只调整命中与仲裁：

- 26键拼音、英语和大小写下，A热区扩到键盘最左边，L扩到左右区域分界前。
- 热区由 `EditorLayout` 统一计算，限定在键盘区域；不侵入正文和右侧操作区。
- 松手沿用按下时保存的按键热区及12px容差。移出后再移回仍取消，不串键、不补发。
- 从按键热区开始的返回手势，声明门槛为原值的2倍；ORANGE/113为24px。
  轻微漂移仍可作为按键点击回放，完整侧滑返回距离保持不变。
- 数字/符号页和九宫格的按键热区不扩展；其他子页面的仲裁门槛及全部页面的完整返回距离保持原状。
- 诊断新增按键外观/热区和键盘分界坐标，只有布局信息，不记录输入正文。

以ORANGE当前配置为例，A外观仍为x=33～87，L为497～551；热区分别为
x=0～91和493～584（右边界不含）。几何来自Falcon配置，不以这些数值判定设备。

### 测试脚本时序修正

首轮设备运行发现脚本的两次Shift之间插入多次ADB诊断读取，超过400ms双击窗口；
改为缓存同一按键坐标后连续点按，没有改变软件的Shift规则。

113固件会缓存测试主动终止原生子进程后的启动页，显示“原生程序已退出（0）”。
测试启动流程使用其现有“重新启动”按钮恢复；不重启宿主，不重置用户数据，
也不修改产品的自动恢复或网络重试策略。首轮失败记录保留在本地日志中。
