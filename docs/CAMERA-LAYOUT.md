# 拍照页布局精修

模式：Operate。沿用深色主题、原生线条图标、完整原图预览及现有拍照／方向行为。
本次用户选择紧凑底部操作区；不调整拍照保存角、Y07固定逆时针90°预览校正或裁剪逻辑。

## 布局

- 竖屏：底部单排“自动／锁定方向—快门—转向90°”。84px中央快门明确主操作，
  两侧为图标和16px短标签，72px高的整块区域可点击。取消两条横贯全屏的灰色按钮。
- 副操作不加常驻卡片底色，按下时用共享surface色反馈；圆角屏底部保留safeBottom。
  预览背景与页面一致，按比例完整显示，不裁切、拉伸或把留白写入照片。
- 横屏：保留右侧窄操作栏，方向与转向图标配单行标签，快门居中。转到窄长工作区时
  使用同样的底排结构，窄标签保留完整显示。所有可操作区域至少44px。
- 快门内圆按外圆尺寸计算并同心；不再固定56px内圆。拍摄进行中忽略方向按钮，
  防止辅助操作在高清采集时重启相机。
- 启动／错误提示避开竖屏左上返回区域。返回仍为现有浮动上下文返回按钮。

## 实现边界

几何集中在`AppLayout::cameraWorkspace`，三个布局类别继续共用相机业务。
`camera_controls`诊断给出页面变换前的实际控件区域，设备脚本以它定位，不再散落
拍照按钮坐标；横屏触摸助手绕逻辑屏中心应用既有逆变换。
新增锁定、自动方向和转向的共享原生图标，不引入图片资源或图标字体。
