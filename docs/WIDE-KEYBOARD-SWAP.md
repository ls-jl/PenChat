# 横屏键盘左右互换与系统输入入口

设置 → 键盘与输入提供“横屏键盘左右互换”，默认关闭。开启后，横屏左右分区编辑器的
键盘区移到右侧，正文、拼音组合、候选、扫描和完成操作移到左侧。只平移两个区域，
不镜像字母顺序、文字方向或按键内容。再次关闭恢复原布局。

设置复用 `app_settings.wide_keyboard_swap`，不修改数据库结构。启动时从已有设置快照
初始化进程内偏好；开关同步更新内存并排队保存。进入编辑器只复制内存偏好，不能因
数据库写锁或缓存失效阻塞输入，活动编辑会话使用固定几何。只在公共
`LayoutClass::WideLandscape`与短横屏展开编辑视图中生效。短横屏默认全宽键盘没有
左右分区，保持原布局；点击放大后，按该偏好交换键区与编辑区，收起后恢复全宽。
竖屏不参与左右互换。设置键沿用原值，已保存的偏好不需要重新配置。

## 几何与交互

`EditorLayout` 的 `keyInset` 是键区原点，`keySpan` 保留键区宽度；`textX/textWidth`
与 `editorPanelX/editorPanelWidth` 给出编辑区。候选展开、密钥显隐、剪贴板、扫描状态
和底部操作均以编辑区为参照。按键命中范围跟随键区平移，单指、双触点 rollover 和
短横屏逆缩放共用同一路径。选择文本专页不参与左右互换。

光标、拖柄与放大镜继续使用真实文本控件的坐标；只约束浮层本身，不能将浮层的屏幕
边界反向用于限制光标。9键拼音的精确拼音栏随键区移动，原始数字码和选词算法不变。
数字、符号和语言菜单沿用相同键区原点。

左右互换后，左侧正文或可见选区拖柄起手的触摸直接交给编辑器，不能先由全局侧滑
返回缓存按下事件，否则450ms长按无法开始。缩放分区的返回仲裁先将触点转换到
同一设计坐标，不能用物理触点直接命中设计画布。原文本区之外的空白左边缘仍保留返回，
按住后的光标／选区拖动可以继续越过编辑区进入键区。

## 有道输入法入口

三类布局的功能栏都移除“官方”按钮。长按地球 **500ms**，在仍按住时打开菜单：

- 26键拼音
- English
- 9键拼音
- 有道输入法

仅明确点击“有道输入法”才打开系统编辑器。它不是第四种内置布局，短按快速轮换仍
只有原来的三项，不改变中文偏好和组合暂存规则。菜单按可用高度限制并允许局部滚动。
系统确认直接完成，取消或发送失败恢复内置编辑状态，沿用现有请求编号和 OCR 清理。

## 定向验证

- `PlatformLayoutTest.cpp` 覆盖960×266、936×280交换／恢复，区域及按键命中平移、
  操作按钮和放大镜边界；640×260、720×280展开视图交换及收起后全宽恢复；
  568×1210与只读选择文本页不参与交换。
- `test_compact_keyboard.py` 覆盖两组短横屏的设置持久化、展开左右互换、字母顺序、
  左边缘长按跨区拖动、剪贴板与官方输入区域、反复收起/展开及关闭设置后恢复。
- `test_wide_keyboard_swap.py` 使用实际主机 LVGL 进程及真实本地拼音词典，覆盖开关
  默认值／持久化、三项短按轮换、500ms按住弹出菜单、明确系统输入选择、英文输入、
  双触点快速输入、候选及展开、剪贴板、官方取消和旧编号隔离。
- 同一进程测试还覆盖互换后的数字／符号／9键拼音筛选、原码回车、从左侧文字和拖柄
  起手跨到键区拖动、放大镜与选区菜单，以及密钥显隐和英文专用官方输入参数。
- 原有编辑器、候选、快速输入及三类布局测试共用更新后的手动官方入口辅助方法。
- `test_startup_recovery.py` 保留6000字及未上屏拼音，检查菜单打开／关闭、动画静止及
  真实socket发送失败后滚动、光标与组合完全不变；菜单重建在最终布局后恢复滚动，
  取消LVGL布局回调开启的滚动动画。`test_storage_ui.py` 在SQLite写锁等待期间使用
  物理点按和长按，要求进入系统输入的响应仍小于1.5秒。
- 截图写入忽略目录 `.work/wide-keyboard-swap/`，不包含用户内容。

屏幕尺寸仅作为主机测试夹具。本次不访问Y02／113；真实设备的触感和官方窗口仍需在
允许的设备上按需验收，不将主机模拟等同于硬件实测。
