# PenChat

独立的 ORANGE 原生 LVGL 聊天应用，版本与 AppID 以 `package.json` 为准。

作者：ls-jl；AI 协作：Codex（OpenAI）。项目地址：<https://github.com/ls-jl/PenChat>。
“设置 → 字体大小”可将聊天正文、思考过程及公式调整为原字号的 75%～150%，支持实时预览、恢复默认和重启记忆；菜单与键盘保持原大小。

内置键盘使用独立 libpinyinime 词典，支持26键拼音、英语、九宫格及本地学习；长按地球可选布局，普通点击中英切换，快速连续点击轮换三种布局。详见[内置编辑器](docs/NATIVE-EDITOR.md)。

软件内可在“设置 → 关于 PenChat”查看署名、版本和项目地址；信息来自 `package.json`。

支持 Responses、Chat Completions 和独立的 Anthropic Messages 接口。Claude 可配置鉴权、API版本、最大输出和思考预算，详见[Anthropic 接入说明](docs/ANTHROPIC-MESSAGES.md)。

Provider 可按需启用 API 兼容模式，调整流式、用量统计、公开思考摘要、加密续传、HTTP/1.1和超时。配置需保存 Provider 后生效；失败不自动重发。详见[API 核查、兼容设置与性能对比](docs/API-COMPATIBILITY.md)。

## 功能

聊天、Markdown/公式、模型与推理强度、历史重命名/置顶/归档、聊天与预设导入导出、自动标题、拍照和相册、正向纸面扫描、系统中文输入法及键盘内单行/多行 OCR。

首次启动没有 Provider、密钥和聊天记录，请在设置中配置模型。聊天数据使用自身 `penchat.db`、DCIM 和图片资产，不导入其他应用的数据库或设置。相册同时只读访问系统 `/userdisk/Pictures`；选中发送时复制到应用资产，保留系统原图。

## 构建

需要 CMake、主机 C/C++ 工具链、aiot-cli、ORANGE AArch64 工具链及扫描资源包。
运行 `npm run build:host`、`npm test`、`npm run test:sanitize`；生产构建使用 `npm run build:native`、`npm run build:prod`、`npm run check:package`。
依赖来源和摘要见 native 下的锁文件；扫描资源准备见 `native/scanner/README.md`。构建脚本重新获取锁定依赖，不提交下载内容或二进制。

设备验收使用明确指定的 ORANGE MEB0400008900794 或113设备 MEA2300009007113；屏幕几何读取Falcon配置。本轮0.2.5仅验收113，ORANGE按用户约定暂缓。安装包位于 dist，以清单中的 AppID 和版本命名。不得重启系统 MiniApp 宿主或修改其他应用的数据。

图标为蜡笔与气泡几何图形，源文件为 `assets/penchat-icon.svg`。PNG 使用 `icon-<SHA256 前 8 位>.png` 内容命名，并由 package.json 的 icon 字段引用；修改图像后同步更新文件名和配置，避免宿主复用旧图片缓存。生产包检查会核对文件名、内容和 manifest。

设置中的“思考过程”支持不展开、思考完毕后收起、始终展开，默认为不展开；手动切换在当前会话浏览期间优先。连续图片按原比例以 140px 为目标高度排列，最大宽度为消息区，超宽图片缩小、小图放大，放不下才换行，并使用圆角。

待发送图片支持长按后确认删除；取消保留图片，删除只移除所选附件及应用副本，不删除系统相册或相机原图。已进入发送请求的图片不能通过此入口删除。

点击聊天中的图片可全屏查看原图，支持双指缩放、双击放大和单指拖动。缩小至能完整显示时，松手自动适应并居中；仅保留悬浮关闭按钮。关闭后保留草稿和阅读位置；查看时流式回复继续接收。长扫描读取原图，图片解码在后台进行并限制内存占用。

历史列表显示最后聊天时间：当天为时分，往日加月日，跨自然年加年份。设置中的“历史时间显示”可选择时间优先、标题优先或关闭列表时间；时间优先时长标题滚动，长按查看静态完整标题与完整日期。关闭显示仍记录实际发送和 AI 回复完成时间，重命名、置顶、归档不会改成聊天时间。缺少可靠旧时间的会话不补造时间。

设置中的“归档会话”可点击标题或“查看”浏览完整聊天；浏览页保留 Markdown、公式、思考展开与原图查看，长聊天按 30 条分页。浏览不还原会话，也不切换当前聊天、草稿或模型；需要继续聊天时，在归档列表中单独点击“还原”。


拍照后进入大画布裁剪页：单指拖动图片，选框保持原位；拖动四边或四角只调整选框范围，双指缩放和平移图片。点击确定后加入待发送聊天区，不立即自动发送。默认不保存相册；勾选“加入系统相册”后将裁剪后的照片保存至系统 `/userdisk/Pictures`，并记住该选择。取消不创建聊天图片或相册照片。

扫描采集与拼接之间使用有界临时队列：短时积压自动排队，松开笔头后处理完剩余帧再显示结果；页面显示待处理数量。孤立单帧缺失会标记并续扫；连续/较大丢帧、存储故障和容量上限仍会提示部分结果，临时队列取消或退出后自动清理。

生产打包会统一对所有暂存的 AArch64 程序和动态库执行 `strip --strip-unneeded`，保留运行所需动态符号；构建目录保留原始文件用于调试。包检查会拒绝残留调试段或私有符号表的 ELF 文件。

HTTP 请求失败、停止生成或进程中断后，可在最新失败消息下点击“重试”；错误弹窗也提供重试。没有新草稿时发送箭头可重试当前问题，继续使用原图片；不会自动重发或重复插入问题。

照片编辑支持最高16倍查看，默认完整原图等比适应可用画布；“还原”恢复初始图片视图和全图选框。预览背景不进入保存结果，最终按原图像素坐标裁剪。触摸配置和图片方向各映射一次，详见[图片手势说明](docs/IMAGE-GESTURES.md)。

相机默认开启加速度计自动方向，稳定判断后切换横屏/竖屏；平放或晃动时保持当前方向。点击“自动方向”可锁定当前方向，“转向 90°”可手动选择四个方向。仅相机和编辑页转向，拍照时旋转真实像素；拍下后冻结编辑方向。ORANGE 已验证横拍 960×720、竖拍 720×960。加速度计只在自动相机期间使用，退出/异常结束恢复原采样状态，不更改系统唤醒设置。

### 会话预设

在“设置 → 会话预设”开启入口后，聊天加号菜单中会出现“预设”（菜单可上下滑动）。
默认预设始终存在；点击设置中的预设可编辑，新增预设可命名和删除。
系统提示词可沿用、自定义或明确清空；模型与推理强度可沿用会话，指定值后可分别选择
“仅空白会话”或“每次切换预设”。“API 默认”是不发送强度参数，与“沿用会话”不同。

历史菜单的新建聊天应用默认预设，上拉新建继承上一会话当前配置。尚未发送的草稿和
待发送图片仍算空白会话。关闭入口不会撤销会话配置；修改或删除预设也不会改写已应用的
会话快照，重新选择才应用新版。模型或强度不可用时保留原选择并提示，不自动降档。

### 原生键盘

默认使用左键盘、右编辑区的原生输入界面。字母行 64px、底行 44px，
左下角切换数字/符号，右侧最上方为候选栏。支持独立拼音候选、九宫格、词频与新词记忆、Shift、
光标移动、全选和 20 步撤销；底部可手动切换官方键盘。
有拼音时空格选词，回车上屏原始字母；“完成”先选词，再点一次才退出。
官方确认直接完成，取消恢复原生编辑。
实现和验证说明见 [原生输入编辑器](docs/NATIVE-EDITOR.md)。

聊天上拉新建可从消息区或输入框文字区域开始；ORANGE 在灵敏度偏移 0% 时满进度距离为 167px，
其他布局按可阅读区域高度等比例调整。设置 → 阅读与交互 → 上滑新建灵敏度可调整
−25%～+25% 偏移，0% 为新版基准；正值更灵敏，负值更稳，支持恢复基准。
附件、发送按钮不参与；空聊天仍不允许上拉新建。详见 [灵敏度设置与验收](docs/PULL-SENSITIVITY.md)。

数据库已支持兼容迁移、500ms 流式保存合并、原子消息更新、SQL 游标分页和后台
图片回收。首次升级会在数据目录保留 SQLite 迁移备份；现有记录与配置不迁出应用。
UI 图标使用共享原生绘制，历史长按操作为单行，首条气泡顶部留白 8px。
实现、恢复注意事项和验证入口见 [数据库与图标说明](docs/STORAGE-AND-ICONS.md)。

聊天与预设可在“设置 → 导入与导出”中备份和恢复。首次启动建立
`/userdisk/Favorite/PenChat` 的导入/导出目录；聊天包附带图片和可读 Markdown，
预设为 JSON。详见 [导入导出格式与操作说明](docs/TRANSFER.md)。

“持久化导出目录”默认开启；关闭后正常退出时清理导出子目录，导入文件保留。

### 会话信息

聊天加号菜单的“会话信息”显示本地上下文估算与最大预算、最近请求及当前保留回复的输入/输出/推理token、缓存读取/写入与命中率，并显示缺失数据的统计覆盖情况。最大值是模型设置的本地预算，服务端硬上限未提供；接口没有返回的用量不当作0。累计不含被覆盖回复、命名和压缩请求，也不代表账单。详见[会话信息说明](docs/SESSION-INFO.md)。

### 上下文压缩

自动上下文压缩默认开启；下一次发送前，达到“模型最大上下文 × 全局压缩阈值”时先生成摘要，阈值默认75%，可设10%～95%。每次成功都保存一份
“压缩前副本”归档。加号菜单可手动压缩及查看摘要，原消息和原图保留。新增模型可离线匹配并预填已核实能力，已有模型只在点击字段旁图标时填充；手动设置优先。未知窗口仍默认
16,384 个估算 token，预设可指定独立压缩模型，留空跟随聊天模型。详见[模型能力库与核验记录](docs/MODEL-CATALOG.md)。失败或取消保留输入，
不自动重试或静默截断历史。详见 [上下文压缩与归档](docs/CONTEXT-COMPRESSION.md)。

### 内置键盘

地球键切换中英文，空格显示“拼音”或“English”。左下123进入数字，ABC直接回字母；
数字页原Shift键切换符号，再次点击返回数字。候选位于右侧顶部，正文支持点按光标、
长按拖动光标、双击选区与拖柄调整；长按选区可全选/复制/粘贴/剪切，无选区静止长按可撤销。
右下依次为取消、官方键盘、扫描模式、完成和应用内剪贴板，退出进程清空剪贴板。内置键盘开启期间禁止下拉控制中心。
键盘就绪后笔头直接使用系统OCR，默认单行，可切换多行；结果插入编辑区，仍需确认输入，
密钥还需单独保存Provider。界面与生命周期约定见 [内置键盘说明](docs/NATIVE-EDITOR.md)。

### Falcon 屏幕配置

原生进程启动时读取 `/etc/miniapp/resources/cfg.json` 的 `screen`，宽高为必填，
旋转与显示偏移用于 DRM。启动器通过 `booted.screen` 获取相同逻辑尺寸，
全屏 hole、输入胶囊、弹层及内置键盘按实际可用区域布局，不回退到固定分辨率。
Falcon 已完成触摸旋转/偏移，应用直接使用逻辑坐标，不重复映射。
主机离屏运行必须用 `--screen-config <JSON路径>` 显式提供配置；测试分辨率只是测试夹具。
屏幕适配不代表扫描硬件兼容：原生扫描仍仅开放已校准的 ORANGE profile。

长按用户消息可复制、选择部分文字或编辑后继续。编辑只在点击发送时覆盖后续对话；
可先归档完整原会话，也可在设置的“编辑消息”中预先选择默认处理方式。完成输入后仍可增删图片，
左上叉号取消并恢复原阅读位置、原待发送图片，文字输入框清空。生成期间不允许编辑。

AI回复下方提供复制、重试、创建分支。重试会先询问是否归档，使用当前配置重答该问题并覆盖后文，
草稿和待发送图片保留且不进入请求。分支保留到该条回复为止的历史，立即打开，草稿和待发送图片随之移动；
原会话的已发送历史不变。分支按“原标题 · 分支、分支2…”命名，不自动发送或调用模型。
