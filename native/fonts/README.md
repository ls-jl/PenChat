# Symbol fallback

Unmodified DejaVu Sans from fonts-dejavu-core 2.37-deepin3, with the upstream licensing notice preserved in LICENSE.txt. Origin: https://dejavu-fonts.github.io/ . SHA256 and byte size are locked in lock.json.

Used only when the system font (or the selected monospace face) lacks a character. This is not complete Unicode coverage or a color emoji/shaping engine. Missing characters beyond both fonts show the fallback font's missing-glyph box rather than disappearing. Font assets and license are staged by scripts/stage-fonts.py.
