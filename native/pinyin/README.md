# PenChat 独立拼音适配

保留 RobinNotBad/libpinyinime 的源码构建、UTF-8 实现和 C API，固定提交、原始文件、
适配后文件与补丁校验值见 `source-lock.json`。`prepare-pinyin.py` 在独立生成目录应用
`penchat.patch`，不使用系统拼音符号、共享 decoder 或预编译输入法库。

0.2.7 的适配重写了候选检索与排序：

- 用音节 Trie 定位前缀，避免每键遍历全部词条及重复分词；全拼、简拼和九键共用索引。
- 保留分词歧义，按覆盖范围、输入匹配代价与词频排序；完整全拼优先，必要时展开简拼。
  辅音首字母仍作为简拼；明确分隔符约束匹配。预计算词频对数，每个终端只扫描其前64项。
- 对精确拼写采用最多4条路径的 Viterbi 束搜索，组合未单列的短句。最多16个词、
  32个汉字、128字节原码、65,536个节点访问、16,384条匹配产出；单位置最多2,048条。
  输出候选限64条，界面使用前48条；用户学习批量合并后再排序，不逐条重排索引。
- 九键精确拼音筛选保留；候选记录实际消费原码的位置，不通过显示文字长度推算。
- 用户词条复用终端节点，避免重复索引表；学习只在完成编辑后应用。用户频率不改变
  基础语料的概率总量，清除记忆会重新加载基础排序。
- 基础词典只读。独立用户增量保留原格式、10,000条/2MiB上限、fsync和原子替换。
  取消、密钥、OCR、粘贴和原码上屏不产生学习。

## 词典

运行资源改为 Rime `rime-pinyin-simp`，其词表注明源于 AOSP PinyinIME，仓库采用
Apache-2.0。固定提交、下载地址、原始 SHA256 与生成结果在 `dictionary-lock.json`；
生成器为 `scripts/prepare-pinyin-dictionary.py`，原始来源保存在忽略的 `.deps/`。

原始65,125条加权记录经拼写别名补全生成65,175条，及音节表合计1,253,849字节（约1.20MiB），低于5MiB软限制。
不再把 libpinyinime 上游附带的旧词表/旧音节表打入安装包；仍保留其原始来源校验值。
新资源、锁及许可证均受生产包检查。保留lve/lue、nve/nue拼写别名，兼容旧音节和已有学习。
用户记忆不进入词典资源或聊天导出包。

固定评价集见 `evaluation.json` 与 `evaluation-heldout.json`；
`python3 tests/test_pinyin_benchmark.py` 使用真实引擎输出排名、延迟和进程RSS。
这些人工样例不代表通用语料准确率或达到系统输入法水平。Viterbi 是有界的一元词频
组合，不是大型语言模型，也没有引入联网补词。

## 0.2.8 保守纠错

键盘与输入中的“拼音纠错”默认开启，只为26键拼音补充候选；原码、回车、
九宫格和英文不变。蓝点标记纠错候选，长按显示正确拼音，松手不选词。
可在设置中关闭；关闭不清除已确认输入产生的正常词频记忆。

音节Trie上的有界单次编辑遍历处理漏字、多字、QWERTY相邻错键及相邻字母颠倒，
包括跨音节颠倒。4～32字母参与纠错，明确分隔符不可修改或跨越；不叠加简拼猜测。
完整精确拼写已有解释时不启动纠错，以免正常词被猜测干扰；因此某些错拼若本身也是
有效拼音，会保留其正常解释。正常完整候选与简拼优先，纠错先于部分匹配。
搜索最多16,384次状态扩展、256个中间结果，最终去重补充不超过8项。
单字纠错仅允许覆盖全部原码；不吞掉精确词后的单个尾字母，避免把下一段输入当成多字。

候选携带标准拼音、实际消费原码范围与纠错标记；查询/选择另校验开关快照及候选版本。
漏字与多字修正不能按标准拼音长度删除原码。只有选词且确认编辑才学习正确拼音；
取消、OCR、粘贴、密钥和原码回车不产生纠错学习。没有错误拼写词库，也不改基础资源。

`evaluation-correction.json` 是40条固定人工单错样例，含本身有合法解释的保守反例。
`tests/test_pinyin_correction_benchmark.py` 对比关闭/开启后的候选、排名、热查询P95、
状态上限和RSS。它不是通用语料准确率测评，最终设备测量也不包含35ms查询合并及绘制。


## 0.2.9 适度放宽

不再因为存在完整精确解释就停止纠错；对这类输入仅补充覆盖全部原码的候选，
至多2项，不改写其正常部分匹配。保留前两个完整正常候选，再插入至多2个纠错候选，
其余正常候选保持原相对顺序。无完整精确解释时仍最多补充8项。
例如 `niao` 保留“鸟、尿”，也可选“你好”；`tiajia` 可选“添加”。
不放宽一次编辑、4～32字母、显式分隔符及搜索容量边界；不加入模糊音或第二处编辑。
原码回车、九宫格、确认学习标准拼音及取消不学习保持不变。

当前回归不再要求开启后整个候选列表逐项相同：保护完整正常首选/前两项、正常词前五
命中和九宫格逐项一致，并检查合法拼写下的新增候选。40条固定错拼集的前五命中
由0.2.8的28/40提高到40/40；这只是固定人工样例，不代表通用准确率。
