# PenChat 独立拼音适配

源码来自 RobinNotBad/libpinyinime，固定提交与归档哈希见 LVGL 依赖锁；
`source-lock.json` 校验原始文件、适配后文件和 `penchat.patch`。
`prepare-pinyin.py` 保留原始解压目录，在独立生成目录应用覆盖并校验，
只把原始 `pinyin.txt` 和 `dictionary.data` 放入只读安装资源。

适配保留上游分词及候选匹配：

- C++14源码构建为静态库，移除计时输出。
- 失败分词位置缓存，避免长无效串产生指数回溯。
- 初始化异常清理，空表或截断资源拒绝加载。
- 只读候选拼音与原文消费位置访问器，独立导入用户增量。
- 选择不立即修改词频或保存全量词典；用户学习由 PenChat 完成编辑后提交。

`PinyinService` 仅在自己的工作线程访问引擎，通过原生事件队列返回结果。
用户增量与只读基础词典分开，数目及序列化体积均受限，持久化经 fsync 和原子替换。
常用中文布局写入现有数据库工作队列，按键不等待 SQLite 写入。

上游 MIT 原文与原词库来源分别保留在许可证清单中；
`THIRD_PARTY_NOTICES.md` 如实列出未独立确认的原始来源授权，不替上游推断许可。
